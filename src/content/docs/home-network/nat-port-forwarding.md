## NAT คืออะไร

NAT ย่อมาจาก Network Address Translation แปลว่าการแปลงที่อยู่เครือข่าย ในเครือข่ายบ้าน อุปกรณ์ทุกเครื่องใช้ [private IPv4](/internet-basics/ip-address/) ตามช่วงที่ RFC 1918 กันไว้ เช่น `192.168.1.x` ซึ่งอินเทอร์เน็ตไม่ส่งต่อให้ ดังนั้น เราเตอร์ ต้องทำหน้าที่แปลที่อยู่ต้นทางของแพ็กเก็ตที่ออกไปให้เป็น IP สาธารณะของ เราเตอร์ เอง

รูปแบบที่ใช้ในบ้านเกือบทั้งหมดคือ NAPT (Network Address Port Translation) ตามที่ RFC 3022 อธิบาย หลายเครื่องในบ้านใช้ IP สาธารณะตัวเดียวร่วมกัน โดย เราเตอร์ แยกว่าแพ็กเก็ตขากลับเป็นของเครื่องไหนด้วยหมายเลขพอร์ต

เปรียบกับห้องรับพัสดุของคอนโด ผู้ส่งจากภายนอกรู้แค่ที่อยู่ตึกเดียว (IP สาธารณะ) เมื่อลูกบ้านสั่งของ นิติบุคคลจดไว้ว่าพัสดุเลขที่นี้ของห้องไหน ของที่ตอบกลับมาจึงถูกส่งถึงห้องที่ถูกต้อง ส่วนคนแปลกหน้าที่ส่งของมาโดยลูกบ้านไม่ได้สั่ง นิติบุคคลไม่รู้ว่าให้ส่งห้องไหน จึงไม่ส่งต่อ นี่คือเหตุผลที่ NAT มีผลเหมือนไฟร์วอลล์เบื้องต้น แม้จะไม่ได้ออกแบบมาเพื่อความปลอดภัยโดยตรง

### ตารางแปลที่อยู่ทำงานอย่างไร

1. เครื่อง `192.168.1.10` เปิดเว็บ ส่งแพ็กเก็ตจากพอร์ตต้นทาง 51000 ไปยังเว็บปลายทางพอร์ต 443
2. เราเตอร์ แปลงต้นทางเป็น IP สาธารณะของตัวเอง กับพอร์ตหนึ่งที่เลือก แล้วจดคู่นี้ไว้ในตาราง
3. เว็บตอบกลับมาที่ IP สาธารณะกับพอร์ตนั้น
4. เราเตอร์ ดูตาราง แปลงกลับเป็น `192.168.1.10` พอร์ต 51000 แล้วส่งให้เครื่องเดิม

RFC 3022 ระบุว่าใน traditional NAT การเชื่อมต่อ (session) เป็นแบบทิศทางเดียว คือเริ่มจากเครือข่ายภายในออกไปข้างนอก ผลที่ตามมา คำขอที่ริเริ่มจากข้างนอกโดยไม่มีรายการในตาราง เราเตอร์ ไม่รู้ว่าต้องส่งต่อให้ใคร จึงทิ้งไป

## Port Forwarding คืออะไร

Port Forwarding (หรือ Port Mapping, Virtual Server ในเมนูของ เราเตอร์ บางยี่ห้อ) คือการเพิ่มรายการในตารางด้วยมือล่วงหน้า บอก เราเตอร์ ว่า "ถ้ามีคำขอเข้ามาที่ IP สาธารณะพอร์ต X ให้ส่งต่อไปที่เครื่อง Y พอร์ต Z ในบ้าน"

![NAT และ Port Forwarding ที่ เราเตอร์ บ้าน](/diagrams/nat-port-forwarding-1.svg)

ค่าที่ต้องกรอกในหน้าตั้งค่า เราเตอร์ ส่วนใหญ่ได้แก่

| ช่อง | ความหมาย | ตัวอย่าง |
|---|---|---|
| External / Public port | พอร์ตที่คนข้างนอกเรียกเข้ามา | 8080 |
| Internal / Private IP | IP ของเครื่องในบ้านที่รับแทน | 192.168.1.20 |
| Internal port | พอร์ตที่โปรแกรมในเครื่องนั้นเปิดรอไว้ | 8080 |
| Protocol | TCP, UDP หรือทั้งสอง | ตามที่โปรแกรมกำหนด |

งานที่ต้องใช้บ่อยคือ เข้ากล้องวงจรปิดหรือ NAS จากข้างนอก เปิดเซิร์ฟเวอร์เกมเองให้เพื่อนเข้า หรือใช้ Remote Desktop เข้าเครื่องที่บ้าน ก่อนเปิดควรรู้ว่าการเปิดพอร์ตคือการยอมให้คนทั้งอินเทอร์เน็ตส่งคำขอเข้ามาถึงเครื่องนั้นได้ จึงควรเปิดเท่าที่จำเป็น และตั้งรหัสผ่านโปรแกรมที่รับคำขอให้แข็งแรง

## CGNAT คืออะไร

CGNAT (Carrier-Grade NAT) คือ NAT ที่ผู้ให้บริการอินเทอร์เน็ตทำเอง เพราะ IPv4 สาธารณะมีไม่พอแจกทุกบ้าน RFC 6888 อธิบายว่าด้วยวิธีนี้ IP สาธารณะหนึ่งตัวถูกแชร์ให้ผู้ใช้หลายราย และ RFC 6598 กันช่วง `100.64.0.0/10` ไว้เป็น Shared Address Space ให้ใช้ระหว่าง เราเตอร์ ของลูกค้ากับอุปกรณ์ CGN ของผู้ให้บริการ

![CGNAT ทำให้มี NAT สองชั้นก่อนถึงอินเทอร์เน็ต](/diagrams/nat-port-forwarding-2.svg)

เมื่อผู้ให้บริการใช้ CGNAT คำขอจากข้างนอกต้องผ่านสองชั้น คือ CGN ของผู้ให้บริการ แล้วจึงถึง เราเตอร์ ของเรา CGN ไม่มีกฎส่งต่อพอร์ตที่ชี้มาที่บ้านเรา ตาราง NAT ชั้นนอกก็สร้างจากการเชื่อมต่อขาออกเหมือนกัน การตั้ง Port Forwarding ที่ เราเตอร์ บ้านจึงไม่มีผลกับคำขอจากอินเทอร์เน็ต RFC 6888 ยังระบุความต้องการของ CGN เรื่องการจัดการพอร์ตที่ต้องแบ่งกันใช้ระหว่างผู้ใช้หลายราย ซึ่งสะท้อนว่าทรัพยากรพอร์ตมีจำกัดเมื่อแชร์ IP

### เปรียบเทียบสถานการณ์ที่พบ

| สถานการณ์ | IP ฝั่ง WAN ของ เราเตอร์ | เปิดพอร์ตเข้าบ้านได้ไหม |
|---|---|---|
| IP สาธารณะของตัวเอง | เป็น IP สาธารณะ และตรงกับที่เว็บเช็ก IP แสดง | ได้ ถ้าตั้งกฎและไฟร์วอลล์ถูกต้อง |
| อยู่หลัง CGNAT | อยู่ในช่วง `100.64.0.0/10` (หรือ private IP ช่วงอื่น) | ไม่ได้ ต้องใช้ทางเลือกอื่น |
| Double NAT ในบ้าน | เป็น private IP เพราะมี เราเตอร์ ตัวอื่นต่อก่อนหน้า | ไม่ได้จนกว่าจะแก้ที่ เราเตอร์ ตัวหน้า |
| เป็น IP สาธารณะแต่ไม่ตรงกับที่เว็บเช็ก IP แสดง | ไม่ตรงกัน | ต้องตรวจเพิ่มว่ามี NAT อื่นคั่นอยู่ |

## เช็กอย่างไรว่าอยู่หลัง CGNAT

1. เข้าหน้าตั้งค่า เราเตอร์ (ปกติเปิดที่ Default Gateway จากคำสั่ง `ipconfig`) แล้วดู **WAN IP** หรือ Internet IP ในหน้า Status
2. เปิดเว็บที่แสดง IP ของผู้เข้าชม (ค้นหา "what is my IP") แล้วจด **public IP**
3. เปรียบเทียบสองค่า

| ผลที่ได้ | ความหมาย |
|---|---|
| WAN IP ตรงกับ public IP | เราเตอร์ ได้ IP สาธารณะของตัวเอง ไม่ได้อยู่หลัง CGNAT |
| WAN IP ขึ้นต้น `100.64.` ถึง `100.127.` | อยู่หลัง CGNAT แน่นอน ตามช่วง Shared Address Space ใน RFC 6598 |
| WAN IP เป็น `10.x.x.x`, `172.16.x.x` ถึง `172.31.x.x` หรือ `192.168.x.x` | มี NAT อีกชั้นก่อนถึง เราเตอร์ (CGNAT ที่ใช้ช่วงอื่น หรือ เราเตอร์ อีกตัวในบ้าน) |
| WAN IP เป็นสาธารณะแต่ไม่ตรงกับ public IP | มี NAT หรือ proxy คั่นอยู่ ควรสอบถามผู้ให้บริการ |

หมายเหตุ ช่วงที่ RFC 1918 กำหนดมี 10/8, 172.16/12 และ 192.168/16

## ทำไมเปิดพอร์ตแล้วยังเข้าไม่ได้

ตั้งกฎถูกแล้วแต่ยังไม่ผ่าน ให้ไล่ตรวจตามลำดับต่อไปนี้

| ลำดับ | สาเหตุ | วิธีตรวจและแก้ |
|---|---|---|
| 1 | อยู่หลัง CGNAT หรือ Double NAT | เทียบ WAN IP กับ public IP ตามหัวข้อข้างบน ถ้าไม่ตรงกัน กฎที่ เราเตอร์ ไม่มีผล |
| 2 | IP ของเครื่องปลายทางเปลี่ยน | เราเตอร์ แจก IP แบบเปลี่ยนได้ กฎเดิมจึงชี้ผิดเครื่อง ตั้งให้ เราเตอร์ จอง IP ให้เครื่องนั้นไว้ หรือกำหนด IP เอง |
| 3 | ไฟร์วอลล์ของเครื่องปลายทางบล็อก | เพิ่มข้อยกเว้นให้โปรแกรมหรือพอร์ตนั้นในไฟร์วอลล์ของระบบปฏิบัติการ |
| 4 | โปรแกรมไม่ได้เปิดรอที่พอร์ตนั้น หรือรับเฉพาะภายในเครื่อง | ตรวจในตั้งค่าโปรแกรมว่าเปิดพอร์ตถูกและรับการเชื่อมต่อจากภายนอก ไม่ใช่เฉพาะ localhost |
| 5 | เลือก protocol ผิด | ตรวจว่าโปรแกรมใช้ TCP หรือ UDP แล้วตั้งให้ตรงกัน หรือเลือกทั้งสอง |
| 6 | ทดสอบจากในบ้านเอง | การเข้า IP สาธารณะของตัวเองจากในเครือข่ายเดียวกันต้องอาศัยความสามารถที่เรียกว่า hairpinning หรือ NAT loopback (RFC 4787 นิยามไว้และกำหนดให้ NAT รองรับสำหรับ UDP) แต่ เราเตอร์ บ้านบางรุ่นไม่รองรับ ให้ทดสอบจากเครือข่ายอื่น เช่น ใช้เน็ตมือถือ |
| 7 | มี เราเตอร์ สองตัวต่อกัน | ตั้งกฎที่ตัวหน้าส่งไปยังตัวหลังด้วย หรือสลับตัวหลังให้เป็นโหมด bridge / access point |
| 8 | ผู้ให้บริการกรองพอร์ตบางหมายเลข | ลองเปลี่ยนพอร์ตภายนอกเป็นหมายเลขอื่น และสอบถามผู้ให้บริการ |

ข้อ 6 เป็นจุดที่พลาดง่าย การทดสอบจากโทรศัพท์ที่ต่อ Wi-Fi บ้านเดียวกันอาจขึ้นว่าเข้าไม่ได้ ทั้งที่จากภายนอกเข้าได้แล้ว

## ถ้าอยู่หลัง CGNAT ทำอะไรได้บ้าง

| ทางเลือก | ทำงานอย่างไร | ข้อจำกัด |
|---|---|---|
| ขอ public IPv4 จากผู้ให้บริการ | ผู้ให้บริการบางรายมีแพ็กเกจหรือบริการเสริมที่ให้ IP สาธารณะ ทำให้ NAT ของ เราเตอร์ ใช้ Port Forwarding ได้ตามปกติ | ขึ้นกับเงื่อนไขของแต่ละผู้ให้บริการ ตัวอย่างหน้าอธิบายแพ็กเกจที่ระบุ Public IPv4 เพื่อใช้เล่นเกมอยู่ใน[บทความแพ็กเกจเกมเมอร์ที่มี Public IPv4](https://aisfibrepro.com/blog/ais-fibre-package-for-gamers-public-ipv4-wifi-7/) |
| ใช้ IPv6 | IPv6 มีที่อยู่เหลือพอให้แต่ละอุปกรณ์มีที่อยู่ของตัวเอง จึงไม่ต้องใช้ NAT เพื่อประหยัดที่อยู่ ต้องเปิดไฟร์วอลล์ของ เราเตอร์ ให้ยอมรับคำขอขาเข้าเฉพาะเครื่องที่ต้องการ | ต้องการให้ทั้งสองฝั่งรองรับ IPv6 |
| ใช้ VPN หรืออุโมงค์ที่เริ่มเชื่อมจากในบ้านออกไป | อุปกรณ์ในบ้านเริ่มเชื่อมขาออกไปยังเซิร์ฟเวอร์กลางหรือบริการ VPN ผู้ใช้ภายนอกเข้ามาผ่านจุดนั้น ซึ่งทำงานได้แม้อยู่หลัง NAT เพราะเป็นการเชื่อมต่อขาออก | ต้องมีเซิร์ฟเวอร์กลางหรือบริการรองรับ |
| ใช้บริการ relay ของอุปกรณ์เอง | กล้องและ NAS หลายรุ่นมีระบบ cloud relay ให้เข้าผ่านแอป ไม่ต้องเปิดพอร์ต | ข้อมูลผ่านเซิร์ฟเวอร์ของผู้ผลิต ตรวจนโยบายก่อนใช้ |

## NAT ช่วยความปลอดภัยแค่ไหน

NAT ทำให้เครื่องภายในไม่ถูกเข้าถึงจากข้างนอกโดยปริยาย เพราะขาเข้าที่ไม่มีรายการในตารางจะถูกทิ้ง แต่นี่เป็นผลข้างเคียงของการออกแบบ ไม่ใช่มาตรการความปลอดภัยเต็มรูปแบบ เมื่อเปิดพอร์ต คำขอจากทั่วโลกเข้าถึงโปรแกรมนั้นได้ทันที ควรอัปเดตเฟิร์มแวร์ของ เราเตอร์ และโปรแกรมที่เปิดรอพอร์ตอยู่เสมอ ใช้รหัสผ่านที่เดายาก และปิดกฎที่ไม่ได้ใช้แล้ว

## คำถามที่พบบ่อย

### NAT กับ Port Forwarding ต่างกันอย่างไร

NAT คือกลไกแปลงที่อยู่ที่ทำงานอัตโนมัติสำหรับการเชื่อมต่อขาออก ส่วน Port Forwarding คือกฎที่ตั้งเองเพื่อให้การเชื่อมต่อขาเข้าผ่านเข้ามาถึงเครื่องที่ระบุได้ Port Forwarding จึงเป็นข้อยกเว้นที่เพิ่มเข้าไปในการทำงานของ NAT

### CGNAT ทำให้เน็ตช้าลงไหม

โดยปกติการท่องเว็บ ดูวิดีโอ และใช้แอปทั่วไปทำงานได้เหมือนเดิม เพราะเป็นการเชื่อมต่อขาออก ผลกระทบหลักอยู่ที่งานที่ต้องให้ผู้อื่นเชื่อมเข้ามาหาเรา เช่น โฮสต์เกม เซิร์ฟเวอร์ส่วนตัว หรือเข้าเครื่องที่บ้านจากข้างนอก

### DMZ คืออะไร ใช้แทน Port Forwarding ได้ไหม

DMZ ในเมนู เราเตอร์ บ้านคือการส่งต่อทุกพอร์ตไปยังเครื่องเดียว ใช้ทดสอบได้เร็วแต่เปิดเครื่องนั้นรับทุกพอร์ตจากอินเทอร์เน็ต เสี่ยงกว่าการเปิดเฉพาะพอร์ตที่ใช้ และถ้าอยู่หลัง CGNAT ก็ไม่ช่วยอยู่ดี

### ทำไมเปิดพอร์ตแล้วเช็กด้วยเว็บตรวจพอร์ตว่าปิดอยู่

อาจเกิดจากอยู่หลัง CGNAT, โปรแกรมยังไม่ได้เปิดรอพอร์ตตอนตรวจ หรือไฟร์วอลล์ของเครื่องบล็อก ลองตรวจตามตารางสาเหตุข้างบนทีละข้อ

### Double NAT คืออะไร แก้อย่างไร

คือมี เราเตอร์ สองตัวทำ NAT ซ้อนกันในบ้าน เช่น ใช้ เราเตอร์ ใหม่ต่อพ่วงหลัง เราเตอร์ เดิม แก้ได้โดยตั้ง เราเตอร์ ตัวหลังเป็นโหมด access point หรือ bridge หรือเปิดกฎส่งต่อที่ตัวหน้าด้วย
