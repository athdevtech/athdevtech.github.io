:::tip[คำตอบสั้น]
IPv6 คือที่อยู่ IP รุ่นใหม่ที่ใช้ตัวเลข 128 บิต ต่างจาก IPv4 ที่ใช้ 32 บิต จึงมีที่อยู่ให้แจกมากพอที่แต่ละอุปกรณ์ในบ้านจะมีที่อยู่ของตัวเอง โดยไม่ต้องแชร์ที่อยู่เดียวผ่าน NAT ส่วนใหญ่เครือข่ายบ้านใช้ IPv4 กับ IPv6 พร้อมกัน (dual stack) เปิดแล้วความเร็วดาวน์โหลดมักไม่ต่างจากเดิม แต่การเชื่อมต่อตรงถึงอุปกรณ์ในบ้านทำได้เรียบง่ายขึ้น เช็กได้ว่าเปิดอยู่หรือไม่จากที่อยู่ที่ขึ้นต้นด้วย 2 หรือ 3 ในเครื่อง หรือจากเว็บทดสอบ IPv6
:::

คำว่า IPv6 โผล่ในหน้าตั้งค่าเราเตอร์ ในผลทดสอบเน็ต และในข่าวเทคโนโลยีอยู่เรื่อย ๆ แต่คนทั่วไปมักไม่แน่ใจว่าตัวเองใช้อยู่หรือไม่ และเปิดแล้วต่างจากเดิมอย่างไร บทความนี้อธิบายว่า IPv6 คืออะไร ต่างจาก IPv4 ตรงไหน ผู้ใช้ตามบ้านจะเห็นผลอะไรบ้าง วิธีเช็กว่าเปิดใช้แล้วหรือยัง และจะทำอย่างไรเมื่อเปิดแล้วมีเว็บบางแห่งช้าหรือเข้าไม่ได้

## IPv6 คืออะไร

IP address คือที่อยู่ที่ใช้ระบุอุปกรณ์บนเครือข่าย เหมือนเลขที่บ้านที่ทำให้ข้อมูลส่งถูกปลายทาง ที่อยู่แบบแรกที่ใช้กันแพร่หลายคือ IPv4 ซึ่งยาว 32 บิต เขียนเป็นเลขสี่ชุดคั่นด้วยจุด เช่น 192.168.1.10 จำนวนที่อยู่ทั้งหมดอยู่ราว 4,300 ล้านค่า ซึ่งน้อยกว่าจำนวนอุปกรณ์ที่ต่ออินเทอร์เน็ตทั่วโลกมานานแล้ว วิธีที่ใช้ยืดอายุคือให้หลายเครื่องในบ้านแชร์ที่อยู่สาธารณะเดียวผ่านเราเตอร์ที่ทำ NAT ซึ่งอธิบายไว้ในบทความ [NAT และ Port Forwarding](/home-network/nat-port-forwarding/)

IPv6 ออกแบบมาแก้ปัญหานี้โดยตรง ข้อกำหนดหลักอยู่ใน [RFC 8200 ของ IETF](https://www.rfc-editor.org/rfc/rfc8200) ซึ่งกำหนดให้ที่อยู่ยาว 128 บิต จำนวนที่อยู่จึงมากจนแต่ละอุปกรณ์ในบ้านมีที่อยู่สาธารณะของตัวเองได้สบาย ไม่ต้องแชร์กัน

หน้าตาของที่อยู่ IPv6 เป็นเลขฐานสิบหกแปดกลุ่ม คั่นด้วยเครื่องหมายทวิภาค เช่น 2001:db8:0:1:0:0:0:10 และเพื่อให้สั้นลง กลุ่มที่เป็นศูนย์ติดกันย่อเป็น :: ได้หนึ่งครั้งต่อที่อยู่ ตัวอย่างข้างต้นจึงเขียนเป็น 2001:db8:0:1::10 ค่า 2001:db8 เป็นช่วงที่สงวนไว้สำหรับเขียนตัวอย่างในเอกสาร ไม่ได้ใช้งานจริง

## IPv6 ต่างจาก IPv4 อย่างไร

| หัวข้อ | IPv4 | IPv6 |
|---|---|---|
| ความยาวที่อยู่ | 32 บิต | 128 บิต |
| หน้าตา | เลขฐานสิบสี่ชุด เช่น 192.168.1.10 | เลขฐานสิบหกแปดกลุ่ม เช่น 2001:db8::10 |
| ที่อยู่สาธารณะต่ออุปกรณ์ | ขาดแคลน จึงมักแชร์ผ่าน NAT | มีพอให้แต่ละอุปกรณ์มีของตัวเอง |
| การตั้งค่าอัตโนมัติ | DHCP | SLAAC หรือ DHCPv6 |
| ส่วนหัวของแพ็กเก็ต | ขนาดแปรผันได้ | ขนาดคงที่ 40 ไบต์ |

ความต่างที่ผู้ใช้สัมผัสได้มากที่สุดคือเรื่อง NAT และการตั้งค่าอัตโนมัติ ส่วนความต่างอื่นเป็นรายละเอียดของโปรโตคอลที่ซ่อนอยู่หลังบ้าน เช่น การจัดการส่วนหัวของแพ็กเก็ต

เรื่องการตั้งค่าอัตโนมัติ IPv4 ในบ้านใช้ DHCP ที่เราเตอร์แจกที่อยู่ให้ทุกเครื่อง ดูหลักการได้ในบทความ DHCP คืออะไร ส่วน IPv6 เครื่องสามารถสร้างที่อยู่ให้ตัวเองได้จากข้อมูลที่เราเตอร์ประกาศ เรียกว่า SLAAC และมี DHCPv6 เป็นอีกทางสำหรับกรณีที่ต้องการควบคุมการแจกมากขึ้น

## ที่อยู่ IPv6 แต่ละชนิดดูอย่างไร

เมื่อเปิดดูที่อยู่ในเครื่อง จะเห็นที่อยู่ IPv6 หลายค่าพร้อมกัน ซึ่งเป็นเรื่องปกติ ชนิดที่ควรแยกให้ออกมีดังนี้

- ที่อยู่ที่ขึ้นต้นด้วย fe80 คือ link-local ใช้คุยกันภายในเครือข่ายวงเดียวเท่านั้น ทุกเครื่องที่เปิด IPv6 จะมีค่านี้เสมอ แม้ผู้ให้บริการยังไม่ได้ให้ IPv6 มาก็ตาม จึงใช้ยืนยันไม่ได้ว่าออกอินเทอร์เน็ตด้วย IPv6 ได้
- ที่อยู่ที่ขึ้นต้นด้วย 2 หรือ 3 คือ global unicast ที่อยู่สาธารณะที่ใช้ติดต่ออินเทอร์เน็ตได้ ถ้าเครื่องมีค่านี้ แสดงว่าเครือข่ายบ้านได้รับ IPv6 จากผู้ให้บริการแล้ว
- ที่อยู่ที่ขึ้นต้นด้วย fc หรือ fd คือที่อยู่ภายในแบบ ULA ใช้ภายในบ้านหรือองค์กร ไม่ถูกส่งออกอินเทอร์เน็ต

เครื่องส่วนใหญ่มักมีที่อยู่ global หลายค่า ค่าหนึ่งคงที่ และอีกค่าเป็นที่อยู่ชั่วคราวที่เปลี่ยนเป็นระยะ เพื่อให้เว็บที่เราเข้าติดตามเครื่องเราได้ยากขึ้น เป็นกลไกด้านความเป็นส่วนตัวที่ระบบปฏิบัติการเปิดให้อยู่แล้ว

## เปิด IPv6 ในเน็ตบ้านแล้วได้อะไร

หลายคนคาดว่าเปิด IPv6 แล้วเน็ตจะเร็วขึ้น ความจริงคือความเร็วดาวน์โหลดและอัปโหลดขึ้นกับแพ็กเกจและคุณภาพสายเป็นหลัก ส่วน IPv6 ไม่ได้เพิ่มความเร็วโดยตัวมันเอง ผลที่เห็นได้จริงมีอยู่ในด้านอื่น

1. ลดปัญหาจาก NAT ซ้อน เมื่อแต่ละอุปกรณ์มีที่อยู่สาธารณะของตัวเอง การต่อตรงจากภายนอกมาถึงกล้องวงจรปิด เครื่อง NAS หรือเซิร์ฟเวอร์ในบ้านจึงตั้งค่าง่ายขึ้น เพราะไม่ต้องทำ port forwarding ผ่านหลายชั้น แต่ต้องเปิดอนุญาตที่ไฟร์วอลล์ของเราเตอร์ให้ตรงอุปกรณ์และพอร์ตที่ต้องการ
2. เกมและแอปที่ต่อกันตรง ๆ ระหว่างผู้ใช้ บางแอปต้องเจาะผ่าน NAT เพื่อให้สองฝั่งคุยกันได้ ถ้าทั้งสองฝั่งมี IPv6 การเชื่อมต่อมักตรงไปตรงมากว่า
3. รองรับอุปกรณ์จำนวนมาก บ้านที่มีอุปกรณ์สมาร์ตโฮมเพิ่มขึ้นเรื่อย ๆ ไม่ต้องกังวลเรื่องที่อยู่หมด

ด้านความปลอดภัย มีความเข้าใจผิดที่พบบ่อยว่าไม่มี NAT แล้วอุปกรณ์จะถูกเข้าถึงจากภายนอกได้ทันที ความจริงคือ NAT ไม่ได้ทำหน้าที่เป็นไฟร์วอลล์โดยตรง สิ่งที่กันการเชื่อมต่อขาเข้าคือกฎของไฟร์วอลล์ เอกสาร RFC 7084 ว่าด้วยข้อกำหนดของเราเตอร์ที่บ้านสำหรับ IPv6 ระบุแนวทางสำหรับเราเตอร์ฝั่งผู้ใช้ไว้ และเราเตอร์ส่วนใหญ่ที่รองรับ IPv6 มักบล็อกการเชื่อมต่อขาเข้าที่ไม่มีใครร้องขอเป็นค่าเริ่มต้น อย่างไรก็ตามควรเปิดหน้าตั้งค่าเราเตอร์ดูว่าตัวเลือกนี้เปิดอยู่ เป็นขั้นตอนพื้นฐานของการตั้งค่าเราเตอร์ให้ปลอดภัย

## เครือข่ายบ้านใช้ IPv4 กับ IPv6 พร้อมกันอย่างไร

ช่วงนี้เว็บและบริการจำนวนมากยังใช้ IPv4 ต่อไป จึงไม่มีบ้านไหนใช้ IPv6 อย่างเดียวได้สมบูรณ์ ผู้ให้บริการจึงมักให้ทั้งสองแบบทำงานคู่กัน เรียกว่า dual stack อุปกรณ์ในบ้านจะมีที่อยู่ทั้ง IPv4 และ IPv6 เมื่อเข้าเว็บ ระบบถามชื่อโดเมนจาก DNS ซึ่งอาจตอบกลับมาทั้งที่อยู่ IPv4 และ IPv6 (ชนิด AAAA) หลักการทำงานของ DNS อ่านได้ในบทความ DNS คืออะไร

คำถามคือเครื่องควรเลือกแบบไหน เอกสาร RFC 8305 เรื่อง Happy Eyeballs อธิบายวิธีที่โปรแกรมใช้ คือลองเชื่อมต่อด้วย IPv6 ก่อน และถ้ายังไม่สำเร็จภายในเวลาสั้น ๆ ก็ลอง IPv4 แทนทันที ผู้ใช้จึงแทบไม่รู้สึกว่าระบบเปลี่ยนไปมา แต่ถ้า IPv6 ของเครือข่ายมีปัญหาในบางเส้นทาง ก็อาจเห็นการโหลดหน้าเว็บสะดุดเล็กน้อยก่อนสลับไปใช้ IPv4

## เช็กอย่างไรว่าเน็ตบ้านใช้ IPv6 อยู่หรือไม่

วิธีเช็กมีสามระดับ เริ่มจากง่ายที่สุด

### เช็กจากเว็บทดสอบ

เปิดเว็บทดสอบอย่าง [test-ipv6.com](https://test-ipv6.com/) ผ่านอุปกรณ์ที่ต่อ Wi-Fi บ้าน เว็บจะทดสอบทั้งการเชื่อมต่อ IPv4 และ IPv6 และรายงานว่าที่อยู่ IPv6 ที่ใช้ออกอินเทอร์เน็ตคือค่าอะไร ถ้าเห็นที่อยู่ IPv6 แสดงว่าใช้อยู่ ถ้าไม่เห็น แสดงว่าเครือข่ายยังออกด้วย IPv4 อย่างเดียว

### เช็กจากเครื่องคอมพิวเตอร์

บน Windows เปิด Command Prompt แล้วพิมพ์ `ipconfig` ดูหัวข้อ IPv6 Address ถ้าเห็นที่อยู่ขึ้นต้นด้วย 2 หรือ 3 แปลว่าเครื่องได้ที่อยู่สาธารณะแล้ว ถ้ามีแค่ fe80 แปลว่ายังได้เฉพาะ link-local บน macOS ดูได้ที่หน้ารายละเอียดของการเชื่อมต่อใน System Settings ส่วนบนมือถือ ดูที่หน้ารายละเอียดของ Wi-Fi ที่ต่ออยู่ ซึ่งบางรุ่นแสดงที่อยู่ IPv6 ไว้ด้วย

ถ้าต้องการลองสื่อสารด้วย IPv6 จริง ใช้คำสั่ง `ping -6` ตามด้วยชื่อเว็บที่รองรับ IPv6 ได้ วิธีอ่านผลของ ping อธิบายไว้ในบทความ ping และ traceroute

### เช็กจากหน้าตั้งค่าเราเตอร์

หน้าสถานะ WAN ของเราเตอร์มักมีช่อง IPv6 แสดงที่อยู่ฝั่งอินเทอร์เน็ตและ prefix ที่ได้รับจากผู้ให้บริการ ชื่อเมนูต่างกันตามยี่ห้อ ถ้าเมนู IPv6 ปิดอยู่หรือแสดงว่าว่างเปล่า อาจเป็นเพราะผู้ให้บริการยังไม่ให้ IPv6 หรือเราเตอร์ตั้งค่าปิดไว้ ทางที่ควรทำคือสอบถามผู้ให้บริการว่ารองรับ IPv6 ในเส้นทางของบ้านนั้นหรือไม่ ก่อนลงมือเปลี่ยนค่าในเราเตอร์

ถ้าอยากรู้ภาพรวมว่าการใช้ IPv6 ทั่วโลกเป็นอย่างไร สถิติ IPv6 ของ Google แสดงสัดส่วนผู้ใช้ที่เข้า Google ผ่าน IPv6 แยกตามประเทศและเปลี่ยนตามเวลา

## เปิด IPv6 แล้วมีปัญหา แก้อย่างไร

อาการที่พบบ่อยและแนวทางไล่เช็กมีดังนี้

- บางเว็บโหลดช้าหรือค้างก่อนขึ้น มักเกิดจากเส้นทาง IPv6 ไปยังเว็บนั้นมีปัญหา ลองปิด IPv6 ที่เครื่องหรือเราเตอร์ชั่วคราวเพื่อเทียบ ถ้าหายแสดงว่าต้นเหตุอยู่ที่ IPv6 ควรแจ้งผู้ให้บริการพร้อมชื่อเว็บที่เจอ
- เครื่องได้แต่ที่อยู่ fe80 แม้เราเตอร์เปิด IPv6 ลองรีสตาร์ตเราเตอร์ และเช็กว่าเฟิร์มแวร์เป็นรุ่นล่าสุด ถ้าใช้เราเตอร์รุ่นเก่ามาก อาจไม่รองรับ IPv6 เต็มรูปแบบ
- อุปกรณ์ที่ต่อผ่าน Access Point หรือเราเตอร์ตัวที่สอง ไม่ได้ IPv6 เพราะอุปกรณ์ชั้นที่สองต้องรองรับและรับ prefix ต่อมาจากตัวหลัก ถ้าใช้เป็นโหมด Access Point ก็ควรได้ผ่านโดยปกติ แต่ถ้าตั้งเป็นเราเตอร์ซ้อนอีกชั้น ต้องตั้งค่าให้ส่งต่อ IPv6 ซึ่งบางรุ่นไม่รองรับ
- กล้องหรืออุปกรณ์เก่าบางตัวทำงานผิดปกติหลังเปิด IPv6 เพราะเฟิร์มแวร์รองรับไม่ครบ ปิด IPv6 เฉพาะเครือข่ายที่อุปกรณ์นั้นใช้ หรืออัปเดตเฟิร์มแวร์ของอุปกรณ์

สิ่งที่ควรระวังคืออย่าปิด IPv6 ถาวรเพียงเพราะเจอปัญหาเล็กน้อยครั้งเดียว ควรไล่ดูว่าปัญหาเกิดกับเว็บใดหรืออุปกรณ์ใด เพราะบริการจำนวนมากเริ่มปรับให้เร็วและเสถียรกว่าเมื่อเข้าผ่าน IPv6

## คำถามที่พบบ่อย

### ใช้ IPv6 แล้วเน็ตเร็วขึ้นไหม

โดยทั่วไปไม่ต่างจากเดิมมาก เพราะความเร็วขึ้นกับแพ็กเกจ คุณภาพสาย และสัญญาณ Wi-Fi ความต่างที่เห็นได้คือเรื่องการเชื่อมต่อแบบตรงและการลดปัญหา NAT ซ้อน

### ต้องซื้อเราเตอร์ใหม่ถึงจะใช้ IPv6 ไหม

ไม่จำเป็นเสมอไป เราเตอร์รุ่นไม่เก่านักส่วนใหญ่รองรับ IPv6 อยู่แล้ว ให้ดูในหน้าตั้งค่าว่ามีเมนู IPv6 หรือไม่ ถ้าไม่มีและเฟิร์มแวร์อัปเดตแล้วก็ยังไม่มี จึงค่อยพิจารณาเปลี่ยน

### IPv6 ปลอดภัยกว่า IPv4 หรือเปล่า

ไม่ได้ปลอดภัยกว่าหรือด้อยกว่าโดยอัตโนมัติ ความปลอดภัยขึ้นกับการตั้งค่าไฟร์วอลล์ รหัสผ่านผู้ดูแล และเฟิร์มแวร์ของเราเตอร์เป็นหลัก ควรตรวจว่าไฟร์วอลล์ IPv6 เปิดอยู่

### ทำไมเว็บทดสอบบอกว่าไม่มี IPv6 ทั้งที่เครื่องมีที่อยู่ fe80

ที่อยู่ fe80 เป็นค่า link-local ที่ใช้ภายในวง LAN เท่านั้น ออกอินเทอร์เน็ตไม่ได้ ต้องมีที่อยู่ที่ขึ้นต้นด้วย 2 หรือ 3 จึงนับว่าได้ IPv6 สำหรับอินเทอร์เน็ต

### ที่อยู่ IPv6 ของเครื่องเปลี่ยนบ่อยหรือไม่

ที่อยู่ชั่วคราวที่ระบบสร้างเพื่อความเป็นส่วนตัวจะเปลี่ยนเป็นระยะ ส่วน prefix ที่ผู้ให้บริการให้บ้านอาจคงที่หรือเปลี่ยนตามนโยบายของผู้ให้บริการ
