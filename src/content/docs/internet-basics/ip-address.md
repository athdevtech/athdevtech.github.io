## IP Address คืออะไร

IP ย่อมาจาก Internet Protocol ซึ่งเป็นชุดกติกาที่กำหนดว่าข้อมูลบนอินเทอร์เน็ตต้องถูกแบ่งเป็นแพ็กเก็ตและส่งต่อกันอย่างไร ทุกแพ็กเก็ตมีที่อยู่ต้นทาง (source) และที่อยู่ปลายทาง (destination) ติดอยู่ในส่วนหัว เราเตอร์ ระหว่างทางอ่านที่อยู่ปลายทางนี้เพื่อตัดสินใจว่าจะส่งแพ็กเก็ตต่อไปทางใด

เปรียบกับงานไปรษณีย์ได้ตรงๆ จดหมายต้องมีที่อยู่ผู้รับเพื่อให้พนักงานคัดแยกส่งต่อ และมีที่อยู่ผู้ส่งเพื่อให้ตอบกลับได้ IP Address ทำหน้าที่เดียวกันในระดับเครือข่าย ต่างกันที่ว่าที่อยู่ไปรษณีย์ใช้ชื่อถนนและเลขที่บ้าน ส่วน IP Address เป็นตัวเลขล้วน ซึ่งคนใช้จำยาก จึงมีระบบ [DNS](/internet-basics/dns/) คอยแปลงชื่อเว็บไซต์ให้เป็นตัวเลขแทน

ข้อกำหนดของ IPv4 ใน RFC 791 ระบุว่าที่อยู่มีความยาว 4 ออกเต็ต (octet) หรือ 32 บิต ส่วน IPv6 ตามที่ RFC 8200 อธิบายขยายขนาดที่อยู่จาก 32 บิตเป็น 128 บิต

## โครงสร้างของ IPv4

IPv4 มี 32 บิต แบ่งเป็น 4 ชุด ชุดละ 8 บิต เมื่อเขียนเป็นเลขฐานสิบแต่ละชุดจึงมีค่าได้ตั้งแต่ 0 ถึง 255 คั่นด้วยจุด เช่น `192.168.1.10`

จำนวนที่อยู่ที่เป็นไปได้ทั้งหมดคือ 2 ยกกำลัง 32 หรือประมาณ 4.3 พันล้านที่อยู่ ตัวเลขนี้ดูมาก แต่ไม่พอให้ทุกอุปกรณ์บนโลกมีที่อยู่ของตัวเอง และบางช่วงถูกกันไว้ใช้งานเฉพาะ ไม่ได้แจกให้ผู้ใช้ทั่วไป เป็นเหตุผลที่ต้องมี NAT ซึ่งให้หลายอุปกรณ์ใช้ IP สาธารณะร่วมกัน (อ่านรายละเอียดใน[บทความเรื่อง NAT และ CGNAT](/home-network/nat-port-forwarding/))

## โครงสร้างของ IPv6

IPv6 มี 128 บิต แบ่งเป็น 8 ชุด ชุดละ 16 บิต เขียนเป็นเลขฐานสิบหก คั่นด้วยโคลอน เช่น `2001:0db8:0000:0000:0000:0000:0000:0001` เนื่องจากยาวมาก RFC 4291 จึงกำหนดวิธีย่อไว้ดังนี้

- ตัดเลขศูนย์นำหน้าในแต่ละชุดได้ เช่น `0db8` เป็น `db8`
- ใช้ `::` แทนชุดที่เป็นศูนย์ล้วนที่อยู่ติดกันหนึ่งชุดขึ้นไป และใช้ได้เพียงครั้งเดียวในหนึ่งที่อยู่
- ตัวอย่างข้างต้นย่อได้เป็น `2001:db8::1`

![เปรียบเทียบโครงสร้างที่อยู่ IPv4 และ IPv6](/diagrams/ip-address-1.svg)

ที่อยู่ `2001:db8::1` และ `203.0.113.5` ในบทความนี้เป็นค่าสมมติสำหรับยกตัวอย่าง

## IPv4 กับ IPv6 ต่างกันอย่างไร

| หัวข้อ | IPv4 | IPv6 |
|---|---|---|
| ความยาวที่อยู่ | 32 บิต | 128 บิต |
| รูปแบบการเขียน | เลขฐานสิบ 4 ชุด คั่นด้วยจุด | เลขฐานสิบหก 8 ชุด คั่นด้วยโคลอน |
| ตัวอย่าง | `203.0.113.5` | `2001:db8::5` |
| จำนวนที่อยู่ | ประมาณ 4.3 พันล้าน (2^32) | 2^128 (มากกว่า IPv4 อยู่ 2^96 เท่า) |
| ฟิลด์ใน header | Time to Live (TTL) | Hop Limit (ชื่อใหม่ของหน้าที่เดิม) |
| การใช้ NAT | ใช้กันทั่วไปเพราะที่อยู่ไม่พอ | มีที่อยู่เหลือพอให้แต่ละอุปกรณ์มีที่อยู่ของตัวเอง จึงไม่ต้องใช้ NAT เพื่อประหยัดที่อยู่ |
| การเข้ากันได้ | ใช้ร่วมกับ IPv6 โดยตรงไม่ได้ | ใช้ร่วมกับ IPv4 โดยตรงไม่ได้ จึงรันคู่กันแบบ dual-stack ช่วงเปลี่ยนผ่าน |

RFC 8200 ระบุว่า Hop Limit ใน IPv6 ลดค่าลง 1 ทุกครั้งที่ผ่าน เราเตอร์ ซึ่งเทียบได้กับฟิลด์ TTL ของ IPv4 ที่ทำหน้าที่ป้องกันแพ็กเก็ตวนในเครือข่ายไม่สิ้นสุด

ในทางปฏิบัติ เครือข่ายบ้านส่วนใหญ่ใช้ทั้งสองแบบพร้อมกัน เรียกว่า dual-stack เว็บที่ยังมีเฉพาะ IPv4 ก็ยังเปิดได้ตามปกติผ่านเครือข่าย dual-stack

## Public IP และ Private IP

ไม่ใช่ทุกที่อยู่ที่เข้าถึงได้จากอินเทอร์เน็ต RFC 1918 กันช่วง IPv4 สามช่วงไว้ให้เครือข่ายภายในองค์กรหรือที่บ้านใช้ได้โดยไม่ต้องขอจากใคร

| ช่วงที่อยู่ | Prefix | จำนวนที่อยู่โดยประมาณ |
|---|---|---|
| 10.0.0.0 – 10.255.255.255 | 10/8 | 16.8 ล้าน |
| 172.16.0.0 – 172.31.255.255 | 172.16/12 | 1.05 ล้าน |
| 192.168.0.0 – 192.168.255.255 | 192.168/16 | 65,536 |

ที่อยู่ในช่วงเหล่านี้ใช้ซ้ำกันได้ในหลายเครือข่ายเพราะไม่ถูกส่งออกไปบนอินเทอร์เน็ตโดยตรง บ้านสองหลังจึงมีเครื่องที่ชื่อ `192.168.1.10` เหมือนกันได้โดยไม่ชนกัน นี่คือเหตุผลที่ เราเตอร์ ตามบ้านส่วนใหญ่แจกที่อยู่ในช่วง `192.168.x.x` ให้อุปกรณ์ภายใน

| | Public IP | Private IP |
|---|---|---|
| ใครกำหนด | ผู้ให้บริการอินเทอร์เน็ตเป็นผู้จัดสรร | เราเตอร์ ภายในบ้านแจกให้ |
| ซ้ำกับคนอื่นได้ไหม | ไม่ได้ ต้องไม่ซ้ำกันบนอินเทอร์เน็ต | ซ้ำได้ระหว่างเครือข่ายที่ต่างกัน |
| เข้าถึงจากอินเทอร์เน็ต | ได้ (ถ้าไม่ถูกกั้นด้วยไฟร์วอลล์) | ไม่ได้โดยตรง |
| ตัวอย่าง | `203.0.113.5` | `192.168.1.10` |

นอกจากนี้ยังมีช่วงพิเศษอื่นที่ IANA บันทึกไว้ใน IANA IPv4 Special-Purpose Address Registry เช่น `127.0.0.0/8` สำหรับ loopback (ตัวเครื่องเรียกหาตัวเอง) และ `100.64.0.0/10` ซึ่ง RFC 6598 กันไว้เป็น Shared Address Space สำหรับผู้ให้บริการที่ใช้ CGNAT ฝั่ง IPv6 มี `::1` เป็น loopback และ `fe80::/10` เป็น link-local ที่ใช้ได้เฉพาะในเครือข่ายเดียวกัน ตามที่ RFC 4291 กำหนด

## IP แบบคงที่และแบบเปลี่ยนไปเรื่อยๆ

IP ของอุปกรณ์ได้มาสองทางหลักๆ

- **กำหนดเอง (static)** ผู้ดูแลพิมพ์ค่าลงในอุปกรณ์เอง เหมาะกับเครื่องที่ต้องการที่อยู่เดิมตลอด เช่น เครื่องพิมพ์ กล้องวงจรปิด หรือ NAS
- **ได้มาอัตโนมัติ (dynamic)** อุปกรณ์ขอจาก เราเตอร์ ผ่านบริการ DHCP ซึ่งแจกที่อยู่ว่างให้ชั่วคราว เป็นค่าเริ่มต้นของโทรศัพท์และคอมพิวเตอร์ทั่วไป

ฝั่ง public IP ก็แบ่งในแนวเดียวกัน หลายบ้านได้ public IP ที่อาจเปลี่ยนเมื่อ เราเตอร์ เชื่อมต่อใหม่ และบางบ้านไม่ได้ public IP ของตัวเองเลยเพราะผู้ให้บริการใช้ CGNAT ผู้ที่ต้องเข้าถึงอุปกรณ์ในบ้านจากภายนอกจึงมักต้องขอ public IP หรือใช้บริการที่ผูกชื่อโดเมนกับ IP ที่เปลี่ยนไปเรื่อยๆ

## วิธีดู IP Address ของเครื่อง

**ดู private IP ของเครื่องตัวเอง**

- Windows: เปิด Command Prompt แล้วพิมพ์ `ipconfig` ดูบรรทัด IPv4 Address
- macOS: พิมพ์ `ifconfig` หรือ `ipconfig getifaddr en0`
- Linux: พิมพ์ `ip addr`
- โทรศัพท์: เข้าการตั้งค่า Wi-Fi แล้วดูรายละเอียดเครือข่ายที่เชื่อมต่ออยู่

**ดู public IP** เปิดเว็บที่แสดง IP ของผู้เข้าชม (ค้นหาคำว่า "what is my IP") ค่าที่ได้คือที่อยู่ที่เว็บปลายทางมองเห็น

ถ้า public IP จากเว็บไม่ตรงกับ IP ฝั่ง WAN ที่หน้าตั้งค่า เราเตอร์ แสดง แปลว่ามี NAT อีกชั้นระหว่าง เราเตอร์ กับอินเทอร์เน็ต อาจเป็น เราเตอร์ อีกตัวในบ้าน หรือ [CGNAT](/home-network/nat-port-forwarding/) ของผู้ให้บริการ ซึ่งส่งผลต่อการเปิดพอร์ตเข้าบ้าน

## IP Address บอกอะไรได้และบอกอะไรไม่ได้

IP Address ที่เห็นจากภายนอกบอกได้คร่าวๆ ว่าผู้ใช้อยู่เครือข่ายของผู้ให้บริการรายใด แต่ไม่ได้ระบุตัวบุคคลหรือบ้านเลขที่แน่ชัด ข้อมูลตำแหน่งจากเว็บค้นหา IP เป็นการประมาณจากฐานข้อมูลของแต่ละเว็บ จึงคลาดเคลื่อนได้ และ private IP ที่ขึ้นต้นด้วย `192.168` ไม่ได้สื่อถึงตำแหน่งใดเลย เพราะทุกบ้านใช้ซ้ำกัน

## คำถามที่พบบ่อย

### IP Address เปลี่ยนได้ไหม

ได้ private IP เปลี่ยนเมื่อ เราเตอร์ แจกที่อยู่ใหม่ให้อุปกรณ์ หรือเมื่อย้ายไปเชื่อมเครือข่ายอื่น ส่วน public IP ของบ้านอาจเปลี่ยนเมื่อ เราเตอร์ เชื่อมต่อใหม่ แล้วแต่นโยบายของผู้ให้บริการ

### IPv6 เร็วกว่า IPv4 ไหม

ไม่ได้เร็วกว่าโดยตัวโปรโตคอลเอง ความเร็วดาวน์โหลดขึ้นอยู่กับแบนด์วิดท์และคุณภาพเส้นทาง สิ่งที่ IPv6 ขยายคือขนาดพื้นที่ที่อยู่ ตามที่ RFC 8200 อธิบาย

### ทำไม IPv4 ยังใช้อยู่ทั้งที่มี IPv6

เพราะเครือข่ายและเว็บไซต์จำนวนมากยังใช้ IPv4 และ NAT ช่วยยืดอายุที่อยู่ให้ใช้ต่อได้ ทั้งสองโปรโตคอลจึงทำงานคู่กันแบบ dual-stack ตลอดช่วงเปลี่ยนผ่าน

### 192.168.1.1 คืออะไร

เป็น private IP ที่ผู้ผลิต เราเตอร์ หลายรายตั้งเป็นที่อยู่ของ เราเตอร์ เอง ใช้เปิดหน้าตั้งค่า แต่ไม่ใช่มาตรฐานตายตัว บางรุ่นใช้ `192.168.0.1` หรือ `10.0.0.1` ให้ดูที่ค่า Default Gateway จากคำสั่ง `ipconfig`

### ใช้ IP Address เดียวกับคนอื่นได้ไหม

ถ้าเป็น private IP ได้ ตราบเท่าที่อยู่คนละเครือข่าย แต่ถ้าเครื่องสองเครื่องในเครือข่ายเดียวกันได้ที่อยู่ซ้ำกัน การเชื่อมต่อจะรวนทั้งคู่ ส่วน public IP ต้องไม่ซ้ำกันทั่วโลก
