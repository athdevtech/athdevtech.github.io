:::tip[คำตอบสั้น]
Wi-Fi roaming คือการที่อุปกรณ์ย้ายการเชื่อมต่อจากจุดกระจายสัญญาณหนึ่งไปอีกจุดหนึ่งโดยใช้เครือข่ายชื่อเดียวกัน คนที่ตัดสินใจย้ายคือมือถือหรือโน้ตบุ๊ก ไม่ใช่เราเตอร์หรือ Mesh จึงเกิดอาการเดินไกลแล้วยังเกาะจุดเดิมที่สัญญาณอ่อน มาตรฐาน 802.11k, 802.11v และ 802.11r ช่วยให้การเลือกและการย้ายเร็วขึ้น แต่ไม่ได้บังคับให้อุปกรณ์ย้าย ถ้าสลับไม่ลื่น ให้เช็กชื่อเครือข่ายและรหัสผ่านว่าเหมือนกันทุกจุด วางจุดให้สัญญาณซ้อนกันพอดี และลองเปิดหรือปิดฟีเจอร์ roaming ทีละตัว
:::

เดินจากห้องนั่งเล่นขึ้นไปห้องนอนชั้นสอง แล้วเน็ตบนมือถือช้าลงทั้งที่ติด Mesh สองตัว หลายคนเข้าใจว่า Mesh ทำงานผิดปกติ ในความเป็นจริงต้นเหตุมักอยู่ที่เรื่อง Wi-Fi roaming ว่าอุปกรณ์ตัดสินใจย้ายจุดเมื่อไร และข้อมูลที่ใช้ตัดสินใจมีมากพอหรือไม่ บทความนี้อธิบายหลักการ บทบาทของ 802.11k, 802.11v และ 802.11r วิธีตั้งค่าในบ้าน และวิธีแก้เมื่อมือถือไม่ยอมสลับจุด

## Wi-Fi roaming คืออะไร

เมื่อบ้านมีจุดกระจายสัญญาณหลายจุด ทั้งแบบ Mesh หรือแบบเราเตอร์หลักกับ Access Point ที่ต่อสาย แต่ละจุดจะกระจายเครือข่ายชื่อเดียวกัน มือถือจะเกาะอยู่กับจุดหนึ่งในแต่ละช่วงเวลา และเมื่อเดินออกห่างจนสัญญาณอ่อน มือถือควรย้ายไปเกาะจุดที่แรงกว่า การย้ายนี้เรียกว่า roaming

ข้อสำคัญคือมาตรฐาน Wi-Fi ให้อุปกรณ์ปลายทางเป็นฝ่ายตัดสินใจย้าย ระบบฝั่งเราเตอร์ทำได้แค่ช่วยแนะนำ ผลคือยี่ห้อและรุ่นของมือถือมีผลมาก มือถือบางรุ่นย้ายเร็ว บางรุ่นเกาะจุดเดิมจนสัญญาณอ่อนมากจึงค่อยย้าย อาการที่เรียกว่า sticky client แบบนี้พบได้ในทุกระบบ ไม่ได้เป็นของเฉพาะ Mesh ยี่ห้อใดยี่ห้อหนึ่ง

## ทำไมมือถือถึงไม่ยอมสลับจุด

เหตุผลหลักมีสามข้อ

1. อุปกรณ์ใช้ความแรงสัญญาณเป็นตัวตัดสิน และแต่ละรุ่นตั้งเกณฑ์ไว้ไม่เท่ากัน ถ้าเกณฑ์ย้ายอยู่ที่สัญญาณอ่อนมาก มือถือก็จะเกาะจุดเดิมนานกว่าที่ควร หลักการอ่านค่า dBm อธิบายไว้ในบทความ [ความแรงสัญญาณ Wi-Fi วัดอย่างไร](/wifi/wifi-signal-strength/)
2. การย้ายมีต้นทุน ต้องสแกนหาจุดอื่น ตรวจสอบสิทธิ์ใหม่ และบางจังหวะข้อมูลที่กำลังส่งอยู่จะสะดุด อุปกรณ์จึงมักไม่ย้ายจนกว่าสัญญาณจะแย่จริง ๆ เพื่อไม่ให้การประชุมวิดีโอหรือการโทรขาดช่วงโดยไม่จำเป็น
3. อุปกรณ์ไม่รู้ว่ามีจุดอื่นให้ย้ายไปที่ไหน ต้องไล่สแกนทีละช่องสัญญาณ ซึ่งช้า และบางเครื่องเลือกไม่สแกนบ่อยเพื่อประหยัดแบตเตอรี่

สามข้อนี้คือสิ่งที่ 802.11k, 802.11v และ 802.11r เข้ามาช่วยแก้ทีละจุด

## 802.11k, 802.11v และ 802.11r ทำอะไร

มาตรฐานทั้งสามเป็นส่วนเสริมของ Wi-Fi ที่พัฒนาโดยคณะทำงาน [IEEE 802.11](https://www.ieee802.org/11/) และผู้ผลิตจำนวนมากรวมไว้ในเราเตอร์และ Mesh หน้าสนับสนุนของ Apple เรื่อง[การรองรับ Wi-Fi roaming ในอุปกรณ์ Apple](https://support.apple.com/en-us/102002) อธิบายหน้าที่ของแต่ละตัวไว้ดังนี้

| มาตรฐาน | ชื่อเรียกสั้น ๆ | ช่วยเรื่องอะไร |
|---|---|---|
| 802.11k | Radio Measurement | ส่งรายการจุดกระจายสัญญาณข้างเคียงให้อุปกรณ์ ไม่ต้องสแกนทุกช่อง |
| 802.11v | Wireless Network Management | ช่วยระบุจุดที่เหมาะที่สุดให้อุปกรณ์ย้ายไป |
| 802.11r | Fast BSS Transition | ทำให้ย้ายจุดได้เร็วและปลอดภัย โดยลดเวลาตรวจสอบสิทธิ์ตอนย้าย |

### 802.11k รายชื่อเพื่อนบ้านที่ใกล้ที่สุด

เมื่อสัญญาณจุดปัจจุบันอ่อนลง อุปกรณ์ต้องหาจุดที่ดีกว่า ถ้าไม่มีข้อมูลล่วงหน้า ต้องสแกนไล่ทีละช่อง ซึ่งเสียเวลา 802.11k ให้จุดกระจายสัญญาณส่งรายการจุดข้างเคียงและช่องสัญญาณของแต่ละจุดมาให้ อุปกรณ์จึงข้ามไปสแกนเฉพาะช่องที่มีโอกาสเจอได้เลย Apple ระบุว่าการสแกนหาจุดย้ายทำได้เร็วขึ้นเมื่อเครือข่ายเปิด 802.11k

### 802.11v ช่วยแนะนำให้ย้าย

802.11v เปิดทางให้จุดกระจายสัญญาณเสนอแนะอุปกรณ์ว่าควรย้ายไปจุดไหน เช่น เมื่อจุดปัจจุบันมีคนต่อเยอะหรือสัญญาณของอุปกรณ์เริ่มแย่ เป็นเพียงคำแนะนำ อุปกรณ์ที่ไม่รองรับหรือเลือกไม่ทำตามก็ยังเกาะจุดเดิมต่อได้ จึงเป็นตัวที่แก้อาการ sticky client ได้บางส่วนเท่านั้น

### 802.11r ย้ายเร็วขึ้น

เครือข่ายที่ใช้รหัสผ่านต้องผ่านขั้นตอนตรวจสอบสิทธิ์ทุกครั้งที่ย้ายไปจุดใหม่ ซึ่งใช้เวลาและทำให้ข้อมูลหยุดไหลชั่วคราว 802.11r ทำให้ขั้นตอนนี้เสร็จเร็วโดยเตรียมคีย์ไว้ล่วงหน้าระหว่างจุด เหมาะกับงานที่ไวต่อการสะดุด เช่น การโทรผ่านอินเทอร์เน็ต อุปกรณ์ที่ไม่รองรับ 802.11r ยังย้ายได้ตามปกติ เพียงใช้ขั้นตอนมาตรฐานที่ช้ากว่า

## ข้อควรรู้ก่อนเปิด 802.11r

ในหน้าตั้งค่าเราเตอร์ บางรุ่นเปิด 802.11r ไว้ให้ บางรุ่นให้เลือกเอง และบางรุ่นมีสามตัวเลือก คือปิด เปิด และเปิดแบบปรับตามอุปกรณ์ ข้อควรรู้มีดังนี้

- อุปกรณ์รุ่นเก่า โดยเฉพาะอุปกรณ์สมาร์ตโฮมบางตัว อาจต่อเครือข่ายที่เปิด 802.11r ไม่ติด หรือหลุดบ่อย ถ้าเริ่มมีอุปกรณ์ต่อไม่ได้หลังเปิด ให้ลองปิด 802.11r เป็นอย่างแรก
- ถ้าบ้านมีอุปกรณ์เก่าปะปนกับอุปกรณ์ใหม่ เราเตอร์บางรุ่นแยกเครือข่ายให้ได้ เช่น ตั้งชื่อเครือข่ายสำหรับอุปกรณ์สมาร์ตโฮมแยกต่างหากโดยไม่เปิด 802.11r
- ควรเปิดทีละตัวแล้วทดสอบ ไม่เปิดทั้งสามพร้อมกันโดยไม่ดูผล เพราะถ้ามีปัญหาจะไม่รู้ว่าตัวไหนเป็นต้นเหตุ

## ตั้งค่าในบ้านอย่างไรให้ roaming ลื่นขึ้น

การตั้งค่าเกินครึ่งหนึ่งไม่เกี่ยวกับมาตรฐานข้างต้นเลย ลองไล่เช็กตามลำดับนี้

1. ชื่อเครือข่าย รหัสผ่าน และชนิดความปลอดภัยต้องเหมือนกันทุกจุด ถ้าตั้งชื่อต่างกัน อุปกรณ์จะมองเป็นคนละเครือข่ายและไม่ roaming ให้เอง ระบบ Mesh ส่วนใหญ่ตั้งให้เหมือนกันอยู่แล้ว แต่ถ้าใช้เราเตอร์กับ Access Point ที่ซื้อแยกกัน ต้องตั้งเองให้ตรง
2. วางจุดให้สัญญาณซ้อนกันพอดี ถ้าวางห่างกันเกินไปจะมีช่องว่างที่สัญญาณอ่อนทั้งสองจุด ถ้าวางชิดกันเกินไปมือถือจะเห็นสัญญาณแรงทั้งคู่และไม่ย้าย หรือเกาะจุดแรกแม้อีกจุดจะอยู่ใกล้กว่า ตำแหน่งที่ดีคือกึ่งกลางระหว่างจุดที่ต้องการครอบคลุม ให้ที่ครึ่งทางสัญญาณยังใช้ได้
3. เช็กช่องสัญญาณ จุดที่อยู่ใกล้กันควรใช้ช่องที่ไม่ชนกัน ระบบ Mesh ส่วนใหญ่จัดการเองได้ แต่ถ้าตั้งเอง ให้ดูหลักการในบทความ [ช่องสัญญาณ Wi-Fi และ Channel Width](/wifi/wifi-channel/)
4. ต่อจุดเข้าด้วยสาย LAN ถ้าทำได้ จุดที่ต่อสายกลับไปเราเตอร์ (wired backhaul) ให้ความเร็วและความเสถียรดีกว่าจุดที่ต่อกันด้วยคลื่นวิทยุ และไม่แย่งแบนด์วิดท์กับอุปกรณ์ที่ใช้งานอยู่
5. อัปเดตเฟิร์มแวร์ ผู้ผลิตแก้ปัญหา roaming ผ่านเฟิร์มแวร์อยู่บ่อย การอัปเดตจึงเป็นขั้นตอนที่ควรทำก่อนปรับค่าละเอียด
6. เปิด Smart Connect หรือ Band Steering อย่างระมัดระวัง ฟีเจอร์นี้รวมชื่อ 2.4 GHz กับ 5 GHz ไว้ด้วยกันและช่วยดันอุปกรณ์ไปย่านที่เหมาะ แต่บางครั้งทำให้อุปกรณ์สมาร์ตโฮมเก่าต่อไม่ได้ ถ้ามีปัญหาให้แยกชื่อ 2.4 GHz ออกมา

บางรุ่นมีค่าปรับกำลังส่งของแต่ละจุด การลดกำลังส่งของจุดที่ซ้อนกันมากเกินไป ช่วยให้มือถือเห็นสัญญาณจุดเดิมอ่อนลงเร็วขึ้นและย้ายไวขึ้น แต่ถ้าลดมากเกินไปจะเกิดช่องว่างที่ไม่มีสัญญาณ ควรปรับทีละน้อยแล้วเดินทดสอบ

## แก้อย่างไรเมื่อมือถือยังไม่ยอมสลับ

ถ้าตั้งค่าตามข้างต้นแล้วยังไม่ลื่น ลองทีละข้อ

- ปิดแล้วเปิด Wi-Fi บนมือถือหนึ่งครั้งเมื่อไปถึงอีกห้อง มือถือจะสแกนใหม่และเลือกจุดที่แรงที่สุด วิธีนี้เป็นทางแก้ชั่วคราวที่ได้ผลเร็ว
- ลบเครือข่ายที่บันทึกไว้แล้วต่อใหม่ ถ้าเคยเปลี่ยนชนิดความปลอดภัยหรือเปิด 802.11r ภายหลัง ข้อมูลเก่าที่เครื่องจำไว้อาจขัดกับค่าใหม่
- เช็กว่ามือถือเปิดโหมดประหยัดแบตเตอรี่หรือไม่ บางรุ่นลดความถี่ในการสแกนหาจุดอื่นเมื่อประหยัดพลังงาน
- ลองใช้อุปกรณ์เครื่องอื่นเดินเส้นทางเดียวกัน ถ้าเครื่องหนึ่งย้ายได้แต่อีกเครื่องไม่ย้าย แสดงว่าต้นเหตุอยู่ที่พฤติกรรมของอุปกรณ์ ไม่ใช่ที่ Mesh
- ดูรายชื่ออุปกรณ์ในแอปของ Mesh ว่าเครื่องเกาะจุดไหนอยู่ตอนนี้ ถ้าแอปแสดงได้ จะเห็นทันทีว่ามือถือยังเกาะจุดเก่าหรือย้ายแล้ว

ถ้าบ้านเป็นพื้นที่กว้างและต้องการให้ย้ายลื่นมากเป็นพิเศษ เช่น คุยโทรศัพท์ผ่าน Wi-Fi ขณะเดินทั่วบ้าน ควรเลือกอุปกรณ์ที่ระบุว่ารองรับ 802.11k, 802.11v และ 802.11r ครบทั้งสามตัวทั้งฝั่งจุดกระจายสัญญาณและฝั่งอุปกรณ์ที่ใช้งาน

## คำถามที่พบบ่อย

### Mesh ย้ายจุดให้มือถืออัตโนมัติได้ไหม

ไม่ได้บังคับได้ทั้งหมด Mesh ทำได้แค่ส่งข้อมูลและคำแนะนำให้อุปกรณ์ ตัวที่ตัดสินใจย้ายจริงคืออุปกรณ์ปลายทาง ระบบบางยี่ห้อมีกลไกตัดการเชื่อมต่อเพื่อบีบให้ย้าย แต่ผลต่างกันไปตามรุ่น

### ควรตั้งชื่อ Wi-Fi ทุกจุดให้เหมือนกันไหม

ควรเหมือนกัน ถ้าต้องการให้ roaming ทำงาน ต้องใช้ชื่อ รหัสผ่าน และชนิดความปลอดภัยเดียวกันทุกจุด ถ้าตั้งชื่อต่างกัน เช่นเพื่อเลือกจุดเอง ก็ต้องสลับด้วยมือ

### 802.11r จำเป็นหรือไม่

ไม่จำเป็นสำหรับการใช้งานทั่วไป ถ้าใช้เว็บและสตรีมมิง การย้ายจุดแบบปกติสะดุดไม่ถึงวินาทีก็ไม่ส่งผลมาก 802.11r มีประโยชน์เมื่อมีการโทรหรือประชุมระหว่างเดิน

### เดินแล้วเน็ตหลุดสั้น ๆ ปกติหรือไม่

หลุดสั้น ๆ ตอนย้ายจุดเกิดได้เป็นปกติ ถ้าหลุดนานหรือบ่อยจนใช้งานไม่ได้ ให้เช็กตำแหน่งวางจุดและช่องสัญญาณก่อน

### ใช้ Access Point หลายตัวต่อสายกับเราเตอร์ได้ roaming เหมือน Mesh ไหม

ได้ถ้าตั้งชื่อ รหัสผ่าน และชนิดความปลอดภัยให้เหมือนกัน และปิด DHCP บน Access Point เพื่อให้มีผู้แจก IP เพียงตัวเดียว แต่การจัดช่องสัญญาณและฟีเจอร์ k/v/r ต้องตั้งเอง ต่างจาก Mesh ที่มักจัดการให้
