:::tip[คำตอบสั้น]
ความแรงสัญญาณ Wi-Fi นิยมแสดงเป็น dBm ซึ่งเป็นค่าติดลบ ยิ่งใกล้ 0 ยิ่งแรง เช่น -50 dBm แรงกว่า -80 dBm สำหรับงานทั่วไปอย่างอ่านอีเมลและเปิดเว็บ ค่าราว -70 dBm ขึ้นไปถือว่าใช้ได้ ส่วนวิดีโอคอลและสตรีมมิงควรได้ราว -67 dBm ขึ้นไป ถ้าต่ำกว่า -80 dBm การส่งข้อมูลมักไม่เสถียร
:::

เวลาเน็ตช้าในบางห้อง คนส่วนใหญ่มักดูจากจำนวนขีดสัญญาณบนหน้าจอ ซึ่งแต่ละอุปกรณ์แปลงจากค่าจริงด้วยสูตรของตัวเอง ทำให้ขีดเท่ากันแต่ความแรงจริงไม่เท่ากัน บทความนี้อธิบายหน่วยที่ใช้วัดความแรงสัญญาณ Wi-Fi ว่า RSSI กับ dBm คืออะไรและต่างกันอย่างไร ค่าเท่าไรจึงเพียงพอสำหรับงานแต่ละแบบ วิธีดูค่าจริงจากเครื่องที่ใช้อยู่ และขั้นตอนแปลผลเมื่อพบว่าสัญญาณอ่อน

## RSSI และ dBm คืออะไร

RSSI ย่อมาจาก Received Signal Strength Indicator เป็นค่าประมาณว่าอุปกรณ์ของเรา "ได้ยิน" สัญญาณจากเราเตอร์หรือจุดกระจายสัญญาณแรงแค่ไหน ตามคำอธิบายของมหาวิทยาลัยมิชิแกน ค่า RSSI ที่ใกล้ 0 หมายถึงแรงกว่า และค่าที่ใกล้ -100 หมายถึงอ่อนกว่า (University of Michigan)

ข้อควรรู้คือ RSSI ไม่ได้ถูกกำหนดให้เป็นหน่วยเดียวกันทั่วโลก MetaGeek อธิบายว่าผู้ผลิตการ์ด Wi-Fi แต่ละรายจัดการ RSSI ต่างกัน บางรายใช้สเกล 0 ถึง 60 บางรายใช้ 0 ถึง 255 จึงมักแปลงเป็น dBm เพื่อให้อ่านเทียบกันได้ ([MetaGeek](https://metageek.com/training/resources/wifi-signal-strength-basics))

| คำ | ความหมาย | ค่าที่พบ |
|---|---|---|
| mW | มิลลิวัตต์ หน่วยกำลังสัญญาณโดยตรง | 1 mW เท่ากับ 0 dBm |
| RSSI | ตัวบ่งชี้ความแรงที่รับได้ ผู้ผลิตกำหนดสเกลเอง | มักเป็น 0 ถึง 60 หรือ 0 ถึง 255 |
| dBm | เดซิเบลเทียบกับ 1 มิลลิวัตต์ ใช้เทียบข้ามอุปกรณ์ได้ | มักอยู่ราว -30 ถึง -100 |

เหตุที่ค่า dBm เป็นลบเพราะกำลังส่งของ Wi-Fi ต่ำมาก เมื่อมาถึงเครื่องรับจึงต่ำกว่า 1 มิลลิวัตต์เสมอ ตัวอย่างจาก MetaGeek คือ -40 dBm เท่ากับ 0.0001 mW การใช้ dBm จึงอ่านง่ายกว่าเลขทศนิยมยาว ๆ

## อ่านค่า dBm อย่างไรให้ถูก

หลักที่ควรจำคือ -30 dBm แรงกว่า -80 dBm เพราะตัวเลขที่ติดลบน้อยกว่าคือสัญญาณแรงกว่า อีกเรื่องหนึ่งคือ dBm เป็นสเกลลอการิทึม ไม่ได้ไล่ระดับเป็นเส้นตรง MetaGeek สรุปเป็น "กฎของเลข 3 และเลข 10" ไว้ดังนี้

- ลดลง 3 dB หมายถึงกำลังสัญญาณเหลือครึ่งหนึ่ง เพิ่มขึ้น 3 dB หมายถึงเป็นสองเท่า
- ลดลง 10 dB หมายถึงกำลังสัญญาณเหลือหนึ่งในสิบ เพิ่มขึ้น 10 dB หมายถึงเป็น 10 เท่า

ผลคือ -60 dBm กับ -70 dBm ต่างกัน 10 เท่าในเชิงกำลัง ทั้งที่ตัวเลขดูห่างกันไม่มาก การที่ค่าลดลงเพียง 10 หน่วยจึงมีผลต่อการใช้งานมากกว่าที่เห็นจากตัวเลข

## ความแรงสัญญาณ Wi-Fi ค่าเท่าไรถึงเรียกว่าดี

MetaGeek แสดงตารางเกณฑ์โดยประมาณ แยกตามงานที่ต้องการ ตัวเลขเหล่านี้เป็นแนวทางจากผู้เชี่ยวชาญด้านเครือข่ายไร้สาย ไม่ใช่ข้อกำหนดของมาตรฐาน IEEE 802.11

| ความแรง | ระดับ | ความหมาย | งานที่ต้องใช้ |
|---|---|---|---|
| -30 dBm | ยอดเยี่ยม | แรงสูงสุดที่ทำได้ ต้องอยู่ห่างจุดกระจายสัญญาณไม่กี่ฟุต ไม่พบบ่อยในการใช้จริง | ไม่เกี่ยวข้อง |
| -67 dBm | ดีมาก | ค่าต่ำสุดสำหรับงานที่ต้องส่งแพ็กเก็ตสม่ำเสมอและตรงเวลา | VoIP สตรีมวิดีโอ |
| -70 dBm | พอใช้ | ค่าต่ำสุดที่ส่งแพ็กเก็ตได้เชื่อถือได้ | อีเมล เปิดเว็บ |
| -80 dBm | ไม่ดี | แค่เชื่อมต่อได้ การส่งแพ็กเก็ตอาจไม่เสถียร | ไม่เกี่ยวข้อง |
| -90 dBm | ใช้ไม่ได้ | ใกล้จมไปกับสัญญาณรบกวนพื้นหลัง แทบไม่มีโอกาสใช้งานได้ | ไม่เกี่ยวข้อง |

MetaGeek ยังระบุว่าถ้าต้องรองรับอุปกรณ์เคลื่อนที่อย่างมือถือและแท็บเล็ต บางผู้เชี่ยวชาญแนะนำ -65 dBm ด้วยซ้ำ ส่วนมหาวิทยาลัยมิชิแกนให้หลักคร่าว ๆ ว่าถ้า RSSI ต่ำกว่า -70 dBm ไม่น่าจะได้ประสิทธิภาพดีสำหรับงานที่ใช้แบนด์วิดท์สูง

ช่วงที่ใช้งานได้จริงในบ้านส่วนใหญ่จึงอยู่ที่ราว -50 ถึง -70 dBm ถ้าอ่านได้ -40 dBm แปลว่ายืนอยู่ใกล้เราเตอร์มาก ส่วนจุดที่ค่าตกลงไปแตะ -75 ถึง -80 dBm เป็นจุดที่ควรเริ่มสงสัยว่ามีปัญหาเรื่องระยะหรือสิ่งกีดขวาง

## SNR คืออะไร ทำไมบางครั้งสัญญาณแรงแต่ยังช้า

นอกจากความแรงของสัญญาณ ยังมีค่า noise หรือสัญญาณรบกวนพื้นหลังจากอุปกรณ์อื่นและเครือข่ายข้างเคียง ค่า SNR (Signal-to-Noise Ratio) คือส่วนต่างระหว่างความแรงสัญญาณกับระดับ noise มีหน่วยเป็น dB เช่น สัญญาณ -60 dBm และ noise -90 dBm จะได้ SNR 30 dB

ตัวอย่างนี้ทำให้เห็นว่า สัญญาณ -60 dBm ที่ดูดีอาจใช้งานได้แย่ ถ้า noise สูงจนเข้าใกล้ -65 dBm เพราะ SNR เหลือเพียงราว 5 dB อุปกรณ์ส่วนใหญ่ที่ใช้ตามบ้านมักแสดงเฉพาะความแรงสัญญาณ ไม่แสดง noise การตรวจ SNR จึงต้องใช้เครื่องมือเฉพาะ เช่น Wireless Diagnostics บน macOS ซึ่งแสดงทั้งสองค่า ถ้าเจอเคสสัญญาณแรงแต่ช้าอย่างต่อเนื่อง ให้ตรวจเรื่อง [ช่องสัญญาณและการชนกันของเครือข่ายข้างเคียง](/wifi/wifi-channel/) ควบคู่ไปด้วย

## วิธีดูค่าความแรงสัญญาณบนเครื่องที่ใช้อยู่

ไม่ต้องติดตั้งโปรแกรมก็ดูค่าพื้นฐานได้จากระบบปฏิบัติการ

| ระบบ | วิธีดู | ค่าที่ได้ |
|---|---|---|
| Windows | เปิด Command Prompt แล้วพิมพ์ `netsh wlan show interfaces` เพื่อดูการเชื่อมต่อปัจจุบัน หรือ `netsh wlan show networks mode=bssid` เพื่อดูเครือข่ายรอบตัว | ช่อง Signal ที่เป็นเปอร์เซ็นต์ตามสเกลของ Windows ไม่ใช่ dBm โดยตรง |
| macOS | กด Option ค้างแล้วคลิกไอคอน Wi-Fi บนแถบเมนู | แสดง RSSI ของเครือข่ายที่เชื่อมต่อ |
| macOS (ทุกเครือข่ายรอบตัว) | Option-click ไอคอน Wi-Fi เลือก Open Wireless Diagnostics แล้วเลือกเมนู Window > Scan | RSSI และ noise ของแต่ละเครือข่าย |
| Linux | พิมพ์ `iwconfig` ในเทอร์มินัล แล้วดูที่ส่วนของการ์ด Wi-Fi | ค่า Signal level |

Microsoft Learn อธิบายว่าคำสั่ง `netsh wlan show interfaces` ใช้แสดงรายการอินเทอร์เฟซ Wi-Fi ที่ตรวจพบในเครื่อง และ `netsh wlan show networks` แสดงเครือข่ายที่มองเห็นในระยะ ([Microsoft Learn](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netsh-wlan)) วิธีที่ใช้บน macOS และ Linux ตรงกับที่มหาวิทยาลัยมิชิแกนแนะนำ

เมื่ออ่านค่าบน Windows เป็นเปอร์เซ็นต์ ให้ใช้เปรียบเทียบจุดต่อจุดภายในเครื่องเดียวกันเท่านั้น อย่านำไปเทียบกับ dBm ของอีกเครื่องโดยตรง เพราะเป็นคนละสเกล

### วิธีวัดให้ได้ข้อมูลที่ใช้ตัดสินใจได้

1. วัดในจุดที่ใช้งานจริง เช่น เตียงนอน โต๊ะทำงาน โซฟาหน้าทีวี ไม่ใช่วัดข้างเราเตอร์อย่างเดียว
2. วัดด้วยอุปกรณ์เครื่องเดียวกันทุกจุด เพื่อตัดผลจากความต่างของการ์ด Wi-Fi
3. วัดแต่ละจุดหลายครั้ง สัญญาณ Wi-Fi แกว่งได้ตามตำแหน่งตัวคนและสิ่งแวดล้อมรอบตัว
4. จดผลเป็นตาราง ห้องไหนเท่าไร แล้วค่อยดูว่าห้องใดต่ำกว่าเกณฑ์ที่ต้องการ
5. ทำ Speed test ที่จุดเดียวกันควบคู่กัน เพื่อดูว่าสัญญาณที่ต่ำนั้นส่งผลต่อความเร็วจริงหรือไม่

ถ้าต้องการขั้นตอนวัดแบบทั่วบ้านพร้อมวิธีหาจุดอับ ลองดู [**ขั้นตอนเช็กสัญญาณ WiFi ให้แรงทั่วบ้านและหาจุดอับ**](https://aisfibrepro.com/blog/วิธีเช็กสัญญาณ-wifi/) ประกอบ

## เมื่อสัญญาณอ่อน ควรแก้ที่อะไรก่อน

สัญญาณที่ลดลงมักมาจากสามเรื่องหลัก คือระยะทาง สิ่งกีดขวาง และสัญญาณรบกวน มหาวิทยาลัยมิชิแกนแนะนำวิธีที่ง่ายที่สุดสองข้อสำหรับสัญญาณอ่อนคือย้ายเครื่องเข้าใกล้เราเตอร์ให้มากที่สุด หรือเสียบสาย Ethernet เพื่อข้าม Wi-Fi ไปเลย

ลำดับที่ควรลองมีดังนี้

| อาการที่เห็น | สาเหตุที่น่าจะเป็น | สิ่งที่ลองก่อน |
|---|---|---|
| ค่าต่ำเฉพาะห้องที่อยู่ไกลหรือมีผนังหนา | ระยะและสิ่งกีดขวาง | ย้ายตำแหน่งเราเตอร์ให้อยู่ใกล้กลางบ้าน ยกให้สูงและไม่วางในตู้ปิด |
| ค่าดีแต่ใช้งานแล้วช้าหรือหลุดเป็นช่วง ๆ | noise หรือเครือข่ายข้างเคียงชนกัน | ปรับช่องสัญญาณและความกว้างช่อง |
| ค่าต่ำเกือบทุกจุดนอกห้องที่มีเราเตอร์ | บ้านใหญ่หรือหลายชั้น เราเตอร์ตัวเดียวครอบคลุมไม่ถึง | พิจารณาเพิ่มจุดกระจายสัญญาณหรือระบบ mesh |
| อุปกรณ์ประจำที่ที่ต้องการความนิ่งสูง เช่น คอมพิวเตอร์ตั้งโต๊ะ | Wi-Fi ไม่จำเป็นสำหรับอุปกรณ์นั้น | ใช้สาย LAN แทน |

เรื่องช่องสัญญาณและย่านความถี่ อ่านเพิ่มได้ในบทความ [ช่องสัญญาณ Wi-Fi และ Channel Width](/wifi/wifi-channel/) ส่วนเรื่องที่ต้องตรวจนอกเหนือจาก Wi-Fi ว่าเน็ตช้าเกิดที่จุดใดของเส้นทาง ดูได้ที่บทความ [ใช้ ping และ tracert ตรวจปัญหาเน็ต](/troubleshooting/ping-traceroute/)

## ข้อผิดพลาดที่พบบ่อย

- **ใช้จำนวนขีดสัญญาณเป็นตัววัด** แต่ละอุปกรณ์แปลงค่าเป็นขีดต่างกัน ควรดูค่าตัวเลขเมื่อต้องเปรียบเทียบ
- **นำค่าจากอุปกรณ์ต่างรุ่นมาเทียบกัน** การ์ด Wi-Fi แต่ละตัวมีเสาอากาศและวิธีรายงานค่าต่างกัน ผลที่ได้จึงต่างกันแม้อยู่จุดเดียวกัน
- **วัดแค่จุดเดียวแล้วสรุปทั้งบ้าน** สัญญาณเปลี่ยนไปตามห้อง ผนัง และตำแหน่งของตัวเราเอง
- **สับสนระหว่างสัญญาณแรงกับความเร็วสูง** ความเร็วที่ได้ขึ้นกับแพ็กเกจ มาตรฐาน Wi-Fi ที่อุปกรณ์รองรับ และจำนวนอุปกรณ์ที่ใช้พร้อมกัน ไม่ได้ขึ้นกับความแรงสัญญาณอย่างเดียว
- **ลืมว่า dBm เป็นสเกลลอการิทึม** ต่างกัน 10 dB คือกำลังสัญญาณต่างกัน 10 เท่า

## คำถามที่พบบ่อย

### สัญญาณ Wi-Fi กี่ dBm ถึงถือว่าดี

ตามเกณฑ์ของ MetaGeek ค่าราว -67 dBm ขึ้นไปดีสำหรับวิดีโอคอลและสตรีมมิง ค่าราว -70 dBm ขึ้นไปพอใช้สำหรับอีเมลและเปิดเว็บ และถ้าต่ำกว่า -80 dBm การส่งข้อมูลอาจไม่เสถียร ตัวเลขเหล่านี้เป็นแนวทาง ไม่ใช่ข้อบังคับ

### RSSI กับ dBm ต่างกันอย่างไร

RSSI เป็นตัวบ่งชี้ความแรงที่ผู้ผลิตการ์ด Wi-Fi กำหนดสเกลเอง บางรายใช้ 0 ถึง 60 บางรายใช้ 0 ถึง 255 ส่วน dBm เป็นหน่วยกลางที่ใช้เทียบข้ามอุปกรณ์ได้ ในทางปฏิบัติหลายเครื่องแปลง RSSI เป็น dBm ก่อนแสดงผล

### ทำไมค่าบน Windows เป็นเปอร์เซ็นต์

คำสั่ง `netsh wlan show interfaces` แสดงช่อง Signal เป็นเปอร์เซ็นต์ตามสเกลของ Windows จึงใช้เปรียบเทียบระหว่างจุดภายในเครื่องเดียวกันได้ แต่ไม่ควรเทียบกับค่า dBm ของเครื่องอื่นโดยตรง

### สัญญาณแรงแล้วทำไมเน็ตยังช้า

สาเหตุที่พบบ่อยคือ noise สูงจน SNR ต่ำ เครือข่ายข้างเคียงใช้ช่องซ้ำกัน หรือแพ็กเกจและอุปกรณ์รองรับความเร็วต่ำกว่าที่คาด ควรทำ Speed test ที่จุดเดียวกันกับที่วัดสัญญาณ แล้วแยกตรวจว่าปัญหาอยู่ที่ Wi-Fi หรืออยู่ที่ต้นทาง

### ใช้สาย LAN แล้วยังต้องดูสัญญาณ Wi-Fi ไหม

ไม่ต้องสำหรับอุปกรณ์ที่ต่อสาย เพราะไม่ผ่านคลื่นวิทยุ มหาวิทยาลัยมิชิแกนระบุว่าการต่อสาย Ethernet ช่วยข้าม Wi-Fi ไปได้เลยเมื่อสัญญาณอ่อน
