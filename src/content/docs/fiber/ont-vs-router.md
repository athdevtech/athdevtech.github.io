:::tip[คำตอบสั้น]
ONT คืออุปกรณ์ที่รับแสงจากสายไฟเบอร์แล้วแปลงเป็นสัญญาณอีเทอร์เน็ต ทำงานในระดับชั้นที่ 2 (Layer 2) ส่วน Router ทำหน้าที่จัดการเครือข่ายในบ้าน ได้แก่ แจก IP (DHCP) แปลงที่อยู่ (NAT) และปล่อย Wi-Fi ส่วน Bridge Mode คือการสั่งให้ ONT ส่งต่อสัญญาณเฉยๆ โดยไม่ทำ NAT หรือ DHCP เพื่อให้เราเตอร์ตัวนอกทำหน้าที่แทนทั้งหมด และหลีกเลี่ยงปัญหา Double NAT
:::

![ภาพอุปกรณ์ ONT และเราเตอร์ไร้สายที่เชื่อมกันด้วยสาย LAN ในบ้าน](/images/ont-vs-router.webp)

หลายบ้านมีกล่องเล็กๆ ติดผนังที่มีสายไฟเบอร์เสียบอยู่ และมีอีกกล่องหนึ่งที่มีเสาอากาศ ไฟกะพริบ และปล่อย Wi-Fi สองกล่องนี้คือ ONT กับ Router ซึ่งทำหน้าที่ต่างกัน บางบ้านได้สองกล่องแยกกัน บางบ้านได้กล่องเดียวที่ทำทั้งสองอย่าง ความเข้าใจเรื่องนี้ช่วยให้เลือกเราเตอร์ใหม่ แก้ปัญหา Wi-Fi และเข้าใจศัพท์อย่าง Bridge Mode ได้ถูกต้อง

## ONT คืออะไร

ONT ย่อมาจาก Optical Network Termination มาตรฐาน ITU-T G.984.1 นิยามว่าเป็น "อุปกรณ์ของผู้ใช้หนึ่งราย ที่ปลายทางข้างหนึ่งของโครงข่ายใยแสง ทำงานตามโปรโตคอล PON และแปลงข้อมูล PON ให้เป็นอินเทอร์เฟซบริการของผู้ใช้" ตัวย่อที่ใกล้กันคือ ONU (Optical Network Unit) ซึ่งเป็นคำกว้างกว่า โดย ONT ถือเป็นกรณีพิเศษของ ONU

พูดให้ง่ายคือ ONT เป็นตัว "แปลภาษา" ระหว่างแสงในเส้นใยกับสัญญาณไฟฟ้าแบบอีเทอร์เน็ตที่คอมพิวเตอร์และเราเตอร์เข้าใจ ถ้าไม่มี ONT สายไฟเบอร์ก็เสียบเข้าอุปกรณ์ในบ้านโดยตรงไม่ได้ เส้นทางของแสงจากชุมสายถึง ONT อธิบายไว้ใน [FTTH และ GPON ทำงานอย่างไร](/fiber/ftth-gpon/)

## Router คืออะไร

Router คืออุปกรณ์ที่เชื่อมเครือข่ายสองวงเข้าด้วยกัน ในบ้านคือเชื่อมเครือข่ายภายใน (LAN) กับอินเทอร์เน็ต ตัวเราเตอร์ตามบ้านมักทำหน้าที่เหล่านี้พร้อมกัน

- **DHCP** แจกที่อยู่ IP ภายในให้ทุกอุปกรณ์ในบ้านอัตโนมัติ ตามโปรโตคอล DHCP
- **NAT** แปลงที่อยู่ IP ภายในของหลายเครื่องให้ออกอินเทอร์เน็ตด้วยที่อยู่สาธารณะเดียว [RFC 3022](https://www.rfc-editor.org/rfc/rfc3022) อธิบายว่า NAT แบบ NAPT แปลงที่อยู่และหมายเลขพอร์ตจำนวนมากให้เหลือที่อยู่เดียว เพื่อเชื่อมเครือข่ายที่ใช้ที่อยู่ส่วนตัวเข้ากับภายนอก
- **ไฟร์วอลล์เบื้องต้น** ตัดการเชื่อมต่อขาเข้าที่ไม่ได้ร้องขอ
- **Wi-Fi (Access Point)** ปล่อยสัญญาณไร้สายให้มือถือและโน้ตบุ๊ก ส่วนใหญ่รวมอยู่ในตัวเราเตอร์ตามบ้าน
- **การยืนยันตัวตนกับผู้ให้บริการ** บางผู้ให้บริการให้เราเตอร์ต่อเข้าด้วย PPPoE (Point-to-Point Protocol over Ethernet) บางรายให้รับ IP ผ่าน DHCP

## ONT กับ Router ต่างกันตรงไหน

| หัวข้อ | ONT | Router |
|---|---|---|
| หน้าที่หลัก | แปลงสัญญาณแสงเป็นสัญญาณอีเทอร์เน็ต | จัดการเครือข่ายในบ้านและเชื่อมออกอินเทอร์เน็ต |
| ชั้นการทำงาน | Layer 2 (เมื่อทำหน้าที่เป็น bridge) | Layer 3 |
| แจก IP (DHCP) | ไม่ทำ ในโหมด bridge | ทำ |
| NAT | ไม่ทำ ในโหมด bridge | ทำ |
| Wi-Fi | ไม่มีในรุ่น bridge ล้วน | มักมีในตัว |
| พอร์ตฝั่งผู้ใช้ | ช่องเสียบสายไฟเบอร์ และพอร์ตอีเทอร์เน็ต | พอร์ต WAN ต่อ ONT และพอร์ต LAN ต่ออุปกรณ์ |

คอลัมน์ของ ONT ใช้ข้อมูลจากการเปรียบเทียบโหมดการทำงานของ ONT ที่ผู้ผลิตอุปกรณ์ PON รายหนึ่งเผยแพร่ไว้ โดยโหมดสะพาน (bridge) ทำงานที่ Layer 2 ส่งเฟรมอีเทอร์เน็ตต่อโดยไม่ทำ NAT และ DHCP ส่วนโหมดเราเตอร์ทำงานที่ Layer 3

## ONT แบบไหนบ้างที่พบตามบ้าน

ผู้ผลิตอุปกรณ์ PON มักแบ่ง ONT สำหรับบ้านเป็นสองกลุ่ม

| ชนิด | ชื่อเต็ม | ลักษณะ |
|---|---|---|
| SFU | Single Family Unit | ทำหน้าที่เหมือน bridge Layer 2 สำหรับเข้าถึงบรอดแบนด์พื้นฐาน ต้องต่อเราเตอร์ภายนอกเพิ่ม |
| HGU | Home Gateway Unit | ONT ที่มีฟังก์ชันเราเตอร์ Layer 3 NAT และ Wi-Fi ในตัว |

ที่มา: คำอธิบายเปรียบเทียบ HGU กับ SFU ของผู้ผลิตอุปกรณ์ PON รายหนึ่ง (ดูแหล่งอ้างอิง) ชื่อเหล่านี้เป็นศัพท์ที่ผู้ผลิตใช้แบ่งรุ่น ONT ไม่ใช่ชื่อรุ่นตามมาตรฐาน

## ตัวอย่างการต่ออุปกรณ์ 3 แบบ

![แผนภาพการต่ออุปกรณ์สามแบบ ได้แก่ ONT แยกกับเราเตอร์ ONT แบบมีเราเตอร์ในตัว และปัญหา Double NAT เมื่อมีเราเตอร์สองตัวทำ NAT ซ้อนกัน](/diagrams/ont-vs-router-1.svg)

**แบบที่ 1 ONT (SFU) + เราเตอร์แยก** เส้นใยแสงเข้า ONT จากนั้นสายอีเทอร์เน็ตจากพอร์ตของ ONT ไปเข้าพอร์ต WAN ของเราเตอร์ เราเตอร์ทำ DHCP NAT และ Wi-Fi ทั้งหมด

**แบบที่ 2 ONT แบบ HGU (กล่องเดียวทำทุกอย่าง)** ONT มีเราเตอร์และ Wi-Fi ในตัว เสียบสายไฟเบอร์แล้วใช้งานได้เลย ตั้งค่าได้จากหน้าเว็บของอุปกรณ์เดียว

**แบบที่ 3 ONT แบบ HGU + เราเตอร์ตัวที่สอง** เจ้าของบ้านซื้อเราเตอร์ที่ดีกว่ามาต่อเพิ่มโดยไม่ได้ปิดฟังก์ชันเราเตอร์ของ ONT เครือข่ายจะมี NAT สองชั้นต่อกัน เรียกว่า Double NAT ซึ่งอธิบายในหัวข้อถัดไป

## Bridge Mode คืออะไร

Bridge Mode (โหมดบริดจ์) คือการตั้งให้ ONT หรือโมเด็มทำหน้าที่เป็นสะพานเชื่อมระดับ Layer 2 เท่านั้น ส่งต่อเฟรมอีเทอร์เน็ตระหว่างฝั่งเครือข่ายผู้ให้บริการกับเราเตอร์ตัวนอก โดยไม่แก้ไขที่อยู่ IP ไม่ทำ NAT และไม่แจก IP ผู้ผลิตที่เผยแพร่คำอธิบายนี้ระบุว่าการตัดสินใจเรื่องการจัดเส้นทาง (routing) ทั้งหมดจะถูกย้ายไปที่อุปกรณ์ภายนอก เช่น เราเตอร์หรือไฟร์วอลล์ตัวที่ผู้ใช้ต่อเอง

ขั้นตอนทั่วไปที่ผู้ผลิตรายนี้อธิบายไว้ คือเข้าหน้าตั้งค่าของ ONT เลือกประเภทการเชื่อมต่อ WAN เป็น Bridge บันทึกและรีบูต แล้วให้เราเตอร์ตัวนอกจัดการ PPPoE หรือ DHCP เอง ทั้งนี้เมนูและชื่อเรียกต่างกันตามรุ่นและผู้ให้บริการ ต้องดูคู่มือของอุปกรณ์ที่ใช้อยู่เป็นหลัก

### เมื่อไรควรใช้ Bridge Mode

- ต้องการใช้เราเตอร์ของตัวเองที่มีฟังก์ชันที่ ONT ไม่มี เช่น VPN, VLAN, QoS ละเอียด หรือเฟิร์มแวร์ที่อัปเดตต่อเนื่อง
- ต้องการให้เราเตอร์ตัวเดียวรับผิดชอบ NAT และไฟร์วอลล์ทั้งเครือข่าย
- ต้องการลดปัญหา Double NAT

### เมื่อไรไม่จำเป็นต้องใช้

- ใช้ ONT แบบ HGU เป็นเราเตอร์หลักอยู่แล้ว และแค่เพิ่มจุดกระจายสัญญาณ Wi-Fi ตัวที่สอง ซึ่งตั้งตัวที่สองเป็น Access Point ได้โดยไม่ต้องแตะโหมดของ ONT
- ผู้ให้บริการบางรายกำหนดให้ใช้อุปกรณ์ที่ติดตั้งให้ ควรตรวจเงื่อนไขก่อนเปลี่ยนโหมด

## Double NAT คืออะไร และสังเกตอย่างไร

Double NAT เกิดเมื่อมี NAT ซ้อนกันสองชั้น คือทั้ง ONT แบบ HGU และเราเตอร์ที่ต่อตามหลังต่างก็ทำ NAT ผู้ผลิตอุปกรณ์ที่เขียนคู่มือเรื่อง bridge mode ระบุว่าอาจทำให้เกิดอาการช้าหรือเชื่อมต่อผิดพลาด และแนะนำให้แก้โดยเปิด bridge mode ที่ ONT หรือปิด NAT ที่เราเตอร์ตัวนอก (ในเราเตอร์บ้านทั่วไป วิธีที่ปลอดภัยกว่าคือสลับเราเตอร์ตัวนอกเป็นโหมด Access Point)

วิธีสังเกตอย่างง่าย: เปิดหน้าตั้งค่าของเราเตอร์ตัวที่ต่อตามหลัง ดูที่อยู่ IP ฝั่ง WAN ถ้าเป็นช่วงที่อยู่ส่วนตัวตาม [RFC 1918](https://www.rfc-editor.org/rfc/rfc1918) ซึ่งได้แก่ 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255 หรือ 192.168.0.0–192.168.255.255 แปลว่ามี NAT อีกชั้นอยู่ข้างหน้าเราเตอร์ตัวนี้ ซึ่งอาจเป็น ONT ในบ้านเอง หรือบางกรณีเป็น NAT ที่ฝั่งผู้ให้บริการ (ดู [NAT, CGNAT และ Port Forwarding คืออะไร](/home-network/nat-port-forwarding/))

ผลที่พบบ่อยของ Double NAT คือการตั้ง port forwarding บนเราเตอร์ตัวหลังแล้วไม่ได้ผล เพราะต้องเปิดพอร์ตที่ ONT อีกชั้นหนึ่งด้วย

## ใช้ Router ของตัวเองกับ ONT ของผู้ให้บริการได้ไหม

โดยหลักการทำได้ หากต่อเราเตอร์เข้าพอร์ตอีเทอร์เน็ตของ ONT และตั้งค่าให้ตรงกับที่ผู้ให้บริการกำหนด เช่น รับ IP ผ่าน DHCP หรือใส่ชื่อผู้ใช้และรหัสผ่านของ PPPoE ถ้า ONT เป็นแบบมีเราเตอร์ในตัว ควรสลับเป็น bridge หรือปิด NAT เพื่อหลีกเลี่ยง Double NAT ส่วนเงื่อนไขว่าผู้ให้บริการอนุญาตให้ใช้เราเตอร์ของตัวเองหรือไม่ และ ONT เป็นของใคร ขึ้นกับสัญญาของแต่ละราย ตัวอย่างการอธิบายกรณีของผู้ให้บริการรายหนึ่งอยู่ใน[บทความเรื่อง Router และ ONT ว่าเป็นของลูกค้าหรือของเช่า](https://aisfibrepro.com/blog/ais-fibre-router-ont-owned-or-rental/)

หลังเปลี่ยนมาใช้เราเตอร์ของตัวเอง ควรตั้งรหัสผ่านผู้ดูแลระบบและปิดบริการที่ไม่จำเป็น ดูแนวทางใน [ตั้งค่า Router ที่บ้านให้ปลอดภัย ทำอะไรได้บ้าง](/security/secure-home-router/)

## คำถามที่พบบ่อย

### ONT ไม่มี Wi-Fi ใช่ไหม

ขึ้นกับรุ่น ONT แบบ SFU ทำหน้าที่ bridge ไม่มี Wi-Fi ในตัว ส่วนแบบ HGU มี Wi-Fi และเราเตอร์ในตัว

### ถอด Router ออกแล้วต่อคอมพิวเตอร์เข้า ONT โดยตรงได้ไหม

ทำได้ในบางกรณี แต่ผลขึ้นกับว่า ONT ทำงานเป็น bridge หรือเป็นเราเตอร์ และผู้ให้บริการต้องการให้ยืนยันตัวตนอย่างไร ถ้าต้องใช้ PPPoE คอมพิวเตอร์ต้องตั้งค่าเอง ซึ่งการต่อเครื่องเดียวตรงเข้า ONT ยังไม่มีไฟร์วอลล์ของเราเตอร์คั่นไว้ด้วย

### เปิด Bridge Mode แล้วเน็ตหลุดเกิดจากอะไร

มักเกิดจากเราเตอร์ตัวนอกยังไม่ได้ตั้งค่า WAN ให้ตรงกับบริการ เช่น ต้องใส่ PPPoE หรือเลือก DHCP ผู้ผลิตแนะนำให้บันทึกค่าและรีบูต ONT หลังเปลี่ยนโหมด และถ้ายังใช้เน็ตไม่ได้ให้ขอ IP ใหม่ (renew) ที่เราเตอร์หรือคอมพิวเตอร์ หากยังไม่ได้ผลให้ตรวจค่าที่ผู้ให้บริการแจ้งไว้

### Bridge Mode ทำให้เน็ตเร็วขึ้นไหม

ไม่ใช่ตัวเพิ่มความเร็วโดยตรง ความเร็วหลักถูกกำหนดโดยบริการและสายไฟเบอร์ ส่วนที่ได้คือลดชั้น NAT ที่ซ้อนกัน และให้เราเตอร์ที่มีประสิทธิภาพมากกว่าเป็นผู้จัดการทราฟฟิกภายในบ้านแทน
