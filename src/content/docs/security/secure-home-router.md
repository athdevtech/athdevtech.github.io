การตั้งค่าเราเตอร์ ที่บ้านให้ปลอดภัยเริ่มจาก 4 เรื่องหลัก คือเปลี่ยนรหัสผ่านหน้าตั้งค่าของเราเตอร์ อัปเดตเฟิร์มแวร์ ใช้การเข้ารหัส WPA3-Personal หรือ WPA2 AES พร้อมรหัส Wi-Fi ที่ยาวและไม่ซ้ำ และปิด WPS, Remote Management กับ UPnP ที่ไม่จำเป็น แล้วเปิด Guest Wi-Fi แยกอุปกรณ์ IoT ออกมา ทั้งหมดนี้ทำได้เองในหน้าตั้งค่าของเราเตอร์ โดยไม่ต้องซื้ออุปกรณ์เพิ่ม
:::

![ภาพประกอบเราเตอร์ ที่บ้านพร้อมไอคอนกุญแจและเครื่องหมายถูก แสดงการตั้งค่าความปลอดภัย](/images/secure-home-router.webp)

การตั้งค่าเราเตอร์ ที่บ้านให้ปลอดภัยมักถูกมองข้าม เพราะเราเตอร์ ส่วนใหญ่ถูกติดตั้งครั้งเดียวแล้วใช้ไปหลายปีโดยไม่มีใครเปิดหน้าตั้งค่าอีกเลย ทั้งที่ทุกอุปกรณ์ในบ้านส่งข้อมูลผ่านเครื่องนี้ บทความนี้รวบรวมสิ่งที่ทำได้จริงตามแนวทางของ CISA (หน่วยงานด้านความมั่นคงปลอดภัยไซเบอร์ของสหรัฐฯ) NCSC ของสหราชอาณาจักร และ Wi-Fi Alliance พร้อมอธิบายเหตุผลของแต่ละข้อ เพื่อให้คุณตัดสินใจเองได้ว่าควรเปลี่ยนอะไรก่อน

## ทำไมต้องตั้งค่าเราเตอร์ ให้ปลอดภัย

CISA อธิบายไว้ในบทความ Securing Network Infrastructure Devices ว่าผู้ที่ควบคุมโครงสร้างการกำหนดเส้นทาง (routing) ของเครือข่ายได้ ก็แทบจะควบคุมข้อมูลที่ไหลผ่านเครือข่ายนั้นได้ทั้งหมด และชี้ปัจจัยที่ทำให้เราเตอร์สำหรับบ้านเป็นเป้าหมายง่าย ได้แก่

- เราเตอร์ขนาดเล็กและรุ่นสำหรับที่อยู่อาศัยแทบไม่มีโปรแกรมป้องกันมัลแวร์หรือเครื่องมือตรวจสอบความถูกต้องของระบบเหมือนคอมพิวเตอร์ทั่วไป
- ผู้ผลิตเปิดบริการบางอย่างไว้ตั้งแต่ต้นเพื่อให้ติดตั้งและใช้งานง่าย ซึ่งอาจมีช่องโหว่
- เจ้าของอุปกรณ์มักไม่เปลี่ยนค่าเริ่มต้น ไม่ปรับแต่งให้รัดกุม และไม่อัปเดตเป็นประจำ
- ผู้ให้บริการอินเทอร์เน็ตอาจไม่เปลี่ยนอุปกรณ์ที่ติดตั้งอยู่ที่บ้านลูกค้า แม้ผู้ผลิตจะเลิกสนับสนุนรุ่นนั้นแล้ว

ส่วนที่ผู้ใช้ควบคุมได้เองคือการเปลี่ยนค่าเริ่มต้น การปิดบริการที่ไม่จำเป็น และการอัปเดต ซึ่งเป็นเนื้อหาของบทความนี้

## ก่อนเริ่ม: เข้าหน้าตั้งค่าเราเตอร์

CISA ระบุว่าข้อมูลเริ่มต้นของเราเตอร์ มักอยู่บนสติกเกอร์ที่ตัวเครื่อง ได้แก่ที่อยู่ IP ชื่อ Wi-Fi (SSID) รหัสผ่าน หมายเลข MAC และชื่อบัญชี ให้เปิดคู่มือของผู้ผลิตประกอบเพราะหน้าตาและชื่อเมนูของแต่ละรุ่นต่างกัน

ถ้าสติกเกอร์ไม่ระบุที่อยู่หน้าตั้งค่า ให้หาที่อยู่ของเราเตอร์ (default gateway) จากเครื่องที่ต่ออยู่ได้ดังนี้

```text
Windows (Command Prompt):   ipconfig            ดูบรรทัด Default Gateway
macOS (Terminal):           route -n get default ดูบรรทัด gateway
Linux (Terminal):           ip route            ดูบรรทัดที่ขึ้นต้นด้วย default via
```

จากนั้นพิมพ์ที่อยู่นั้นในเบราว์เซอร์ เช่น `http://192.168.1.1` (ตัวอย่างเท่านั้น ที่อยู่จริงของแต่ละบ้านอาจต่างกัน) แล้วล็อกอินด้วยบัญชีแอดมิน หลังเปลี่ยนรหัส Wi-Fi อุปกรณ์ทุกเครื่องจะหลุดและต้องกรอกรหัสใหม่ จึงควรทำตอนที่พร้อมเชื่อมต่อใหม่

## เช็กลิสต์ 10 ข้อ

![รายการ 10 ข้อสำหรับตั้งค่าเราเตอร์ ที่บ้านให้ปลอดภัย](/diagrams/secure-home-router-1.svg)

ตารางนี้สรุปแต่ละข้อพร้อมเหตุผลตามที่ CISA ระบุไว้ใน Module 5: Securing Your Home Wi-Fi

| # | สิ่งที่ทำ | เหตุผล |
|---|---|---|
| 1 | เปลี่ยนชื่อผู้ใช้และรหัสผ่านของหน้าตั้งค่าเราเตอร์ | ข้อมูลเริ่มต้นของเราเตอร์ อาจหาได้สาธารณะ |
| 2 | ตรวจและอัปเดตเฟิร์มแวร์ เปิดอัปเดตอัตโนมัติถ้ามี | การอัปเดตตามรอบป้องกันช่องโหว่ที่รู้จักแล้ว |
| 3 | เปลี่ยนรหัส Wi-Fi เป็นวลียาวที่ไม่ซ้ำกับบัญชีอื่น | รหัสที่ยาว สุ่ม และไม่ซ้ำเดาได้ยาก |
| 4 | ใช้ WPA3-Personal หรือ WPA2 AES | เป็นการเข้ารหัสสองแบบที่ CISA ถือว่าปลอดภัยพอ |
| 5 | ปิด WPS | ฟีเจอร์นี้เพิ่มโอกาสที่ผู้โจมตีจะเข้าเครือข่ายได้โดยไม่ได้รับอนุญาต |
| 6 | ปิด Remote Management | กันการเข้าไปแก้ค่าเราเตอร์ จากอินเทอร์เน็ตโดยไม่ต้องเชื่อมต่อเครือข่ายก่อน |
| 7 | ปิด UPnP หลังเพิ่มอุปกรณ์เสร็จ | ผู้โจมตีอาจใช้ UPnP แพร่มัลแวร์และควบคุมอุปกรณ์ในเครือข่ายจากระยะไกล |
| 8 | เปลี่ยนชื่อ Wi-Fi (SSID) และไม่ใส่ข้อมูลส่วนตัว | ชื่อเริ่มต้นอาจบอกรุ่นและช่องโหว่ที่รู้จักของเราเตอร์ |
| 9 | เปิด Guest Wi-Fi แยกสำหรับแขกและอุปกรณ์ IoT | แยกอุปกรณ์เหล่านั้นออกจากเครื่องส่วนตัวและหน้าตั้งค่าเราเตอร์ |
| 10 | วางเครื่องในที่ที่คนอื่นเข้าถึงไม่ง่าย | ผู้ที่จับเครื่องได้สามารถรีเซ็ตเป็นค่าโรงงานและใช้ข้อมูลเริ่มต้นเข้าระบบได้ |

## ตั้งรหัสผ่านให้แข็งแรง

เราเตอร์มักมีรหัสสองชุดที่ใช้ต่างหน้าที่ ควรตั้งทั้งสองชุดให้ต่างกัน

| รหัส | ใช้ทำอะไร | แนวทาง |
|---|---|---|
| รหัสแอดมิน | ล็อกอินเข้าหน้าตั้งค่าเราเตอร์ | เปลี่ยนทั้งชื่อผู้ใช้และรหัสผ่าน ไม่ใช้ซ้ำกับรหัสอื่น |
| รหัส Wi-Fi | ให้อุปกรณ์เชื่อมต่อเครือข่าย | วลีผ่านที่จำง่ายแต่ยาว ไม่ใช้ซ้ำกับบัญชีอื่น |

CISA แนะนำให้ใช้วลีที่ประกอบด้วยคำที่ไม่เกี่ยวข้องกัน 5 ถึง 7 คำ รวมแล้วอย่างน้อย 16 ตัวอักษร และห้ามใช้ชื่อผู้ใช้และรหัสผ่านชุดเดียวกันทั้งบัญชีเราเตอร์ และบัญชีแอดมิน ส่วน NCSC แนะนำวิธีตั้งรหัสผ่านของอุปกรณ์สมาร์ทด้วยการรวมคำสุ่มสามคำ และถ้าอุปกรณ์หรือแอปมีการยืนยันตัวตนสองขั้นตอน (2SV) ให้เปิดใช้ด้วย หน้าตั้งค่าเราเตอร์ส่วนใหญ่รับรหัส Wi-Fi เป็นตัวอักษรภาษาอังกฤษ ตัวเลข และสัญลักษณ์เท่านั้น ให้ใช้คำภาษาอังกฤษหรือคำไทยที่เขียนด้วยตัวอักษรโรมัน

## เลือกการเข้ารหัส Wi-Fi

CISA ระบุว่า WPA3 Personal และ WPA2 AES (บางเครื่องแสดงเป็น WPA2 PSK หรือ WPA2) เป็นสองรูปแบบเดียวที่ถือว่าปลอดภัยพอต่อผู้ที่พยายามดูข้อมูลที่ส่งผ่านเครือข่าย

| ตัวเลือกในหน้าตั้งค่า | สถานะตามแนวทาง CISA และ Apple |
|---|---|
| WPA3-Personal | ใช้ได้ แนะนำถ้าอุปกรณ์รองรับ |
| WPA2 AES (WPA2-PSK) | ใช้ได้ |
| WPA2/WPA3 (Transitional หรือ Mixed) | ใช้ได้เมื่อยังมีอุปกรณ์เก่าที่ไม่รองรับ WPA3 (Apple แนะนำโหมดนี้เพื่อความเข้ากันได้) |
| WPA2 TKIP | รุ่นเก่า ควรเลิกใช้ |
| WPA, WEP | รุ่นเก่า ควรเลิกใช้ |
| Open (ไม่เข้ารหัส) | ไม่ปลอดภัย |

Wi-Fi Alliance ระบุว่าผู้ใช้ WPA3-Personal ได้รับการป้องกันเพิ่มเติมจากการเดารหัสผ่าน และเครือข่าย WPA3 ใช้โปรโตคอลความปลอดภัยรุ่นล่าสุด ไม่อนุญาตโปรโตคอลรุ่นเก่า และบังคับใช้ Protected Management Frames (PMF) ถ้าอุปกรณ์เก่าบางตัวเชื่อมต่อ WPA3 ไม่ได้ ให้ใช้ WPA2 AES ซึ่ง CISA ยังจัดว่าปลอดภัยพอ

ถ้าเราเตอร์ ของคุณมีให้เลือกแค่ Open, WEP, WPA หรือ WPA2 TKIP CISA แนะนำให้ติดต่อผู้ให้บริการอินเทอร์เน็ตที่จัดหาเครื่องให้เพื่อขอเปลี่ยน หรือพิจารณาซื้อเราเตอร์ ใหม่

## ปิดฟีเจอร์ที่เพิ่มความเสี่ยง

| ฟีเจอร์ | ทำหน้าที่อะไร | ทำไม CISA แนะนำให้ปิด | สิ่งที่อาจเปลี่ยนไป |
|---|---|---|---|
| WPS (Wi-Fi Protected Setup) | เชื่อมต่ออุปกรณ์ด้วยปุ่มหรือรหัสสั้นโดยไม่ต้องพิมพ์รหัส Wi-Fi | เพิ่มโอกาสที่ผู้โจมตีเข้าเครือข่ายได้โดยไม่ได้รับอนุญาต | ต้องพิมพ์รหัส Wi-Fi เองเมื่อเชื่อมต่ออุปกรณ์ใหม่ |
| Remote Management | เข้าไปแก้ค่าเราเตอร์ ผ่านอินเทอร์เน็ต | ถ้าปิด ผู้โจมตีต้องเชื่อมต่อเครือข่ายก่อนจึงจะแก้ค่าได้ | ต้องอยู่ที่บ้านจึงแก้ค่าได้ |
| UPnP | ให้อุปกรณ์ในบ้านเปิดพอร์ตให้ตัวเองอัตโนมัติ | ผู้โจมตีอาจใช้แพร่มัลแวร์และควบคุมอุปกรณ์จากระยะไกล | บางเกมหรือแอปอาจต้องตั้งพอร์ตเอง |

CISA ยอมรับว่าบางกรณีต้องเปิด UPnP ชั่วคราวเพื่อเพิ่มอุปกรณ์เข้าเครือข่ายครั้งแรก แต่ให้ปิดอีกครั้งหลังเสร็จ ถ้าปิดแล้วเกมหรือกล้องบางตัวติดต่อภายนอกไม่ได้ ให้เปิดเฉพาะพอร์ตที่จำเป็นด้วยตนเอง ดูวิธีได้ที่บทความ [NAT, CGNAT และ Port Forwarding คืออะไร](/home-network/nat-port-forwarding/)

NCSC แนะนำเรื่องใกล้เคียงกันสำหรับอุปกรณ์สมาร์ท คือถ้าไม่จำเป็นต้องเข้าถึงอุปกรณ์จากนอกบ้านให้ปิดฟีเจอร์เข้าถึงระยะไกล (remote access)

## อัปเดตเฟิร์มแวร์

เฟิร์มแวร์คือซอฟต์แวร์ที่ทำงานอยู่ภายในเราเตอร์ CISA ระบุว่าการอัปเดตตามรอบช่วยป้องกันช่องโหว่ที่เป็นที่รู้จักแล้ว และบางเครื่องตั้งอัปเดตอัตโนมัติได้ ส่วน NCSC อธิบายว่าผู้ผลิตต้องออกอัปเดตเพื่อแก้บั๊กและปัญหาความปลอดภัย ถ้าไม่ติดตั้ง อุปกรณ์จะถูกโจมตีได้ง่ายขึ้น

สิ่งที่ควรทำ

1. เปิดหน้าตั้งค่าเราเตอร์ แล้วหาเมนูที่เกี่ยวกับ Firmware, System หรือ Update
2. ถ้ามีตัวเลือกอัปเดตอัตโนมัติให้เปิดไว้
3. ติดตั้งอัปเดตแบบกดเองเมื่อระบบแจ้ง และอย่าตัดไฟระหว่างอัปเดต
4. ถ้าเราเตอร์ ติดตั้งโดยผู้ให้บริการและไม่มีเมนูอัปเดต ให้สอบถามผู้ให้บริการว่าเฟิร์มแวร์ถูกจัดการจากส่วนกลางหรือไม่

## แยกอุปกรณ์ด้วย Guest Wi-Fi

![แผนภาพเราเตอร์ แยกเครือข่ายหลักและ Guest Wi-Fi สำหรับแขกและอุปกรณ์ IoT](/diagrams/secure-home-router-2.svg)

CISA แนะนำให้เปิด Guest Wi-Fi ถ้าเราเตอร์ มีให้ และตั้งรหัสที่ยาว สุ่ม ไม่ซ้ำให้ต่างจากเครือข่ายหลัก ผู้ที่ไม่ได้ใช้เครือข่ายหลักเป็นประจำควรเชื่อมต่อผ่านเครือข่ายนี้ นอกจากนี้อุปกรณ์สมาร์ทและ IoT ที่ต้องการแค่อินเทอร์เน็ตควรเชื่อมกับ Guest Wi-Fi เพื่อไม่ให้ค้นหาอุปกรณ์อื่นในบ้าน เข้าถึงหน้าตั้งค่าเราเตอร์ หรือนำช่องโหว่เข้ามาในเครือข่ายหลัก

ข้อควรระวัง อุปกรณ์ที่ต้องคุยกับเครื่องอื่นในบ้านโดยตรง เช่น เครื่องพิมพ์ที่ใช้ร่วมกัน NAS หรือกล้องที่ดูผ่านแอปในเครือข่ายเดียวกัน อาจใช้งานไม่ได้เมื่อย้ายไป Guest Wi-Fi ให้ลองทีละเครื่องและย้ายกลับถ้าใช้งานไม่ได้

## ถ้าใช้เราเตอร์ ที่ผู้ให้บริการติดตั้งให้

เราเตอร์บางรุ่นที่มากับบริการอินเทอร์เน็ตถูกล็อกบางเมนู หรือถูกจัดการเฟิร์มแวร์จากส่วนกลาง ทำให้ปรับได้ไม่ครบทุกข้อ แนวทางปฏิบัติคือ ทำเท่าที่เมนูอนุญาต โดยเฉพาะเปลี่ยนรหัสแอดมิน รหัส Wi-Fi และชื่อ Wi-Fi จากนั้นสอบถามผู้ให้บริการถึงข้อที่แก้เองไม่ได้ และถ้าต้องการควบคุมค่าทั้งหมดเองจึงพิจารณาใช้เราเตอร์ ของตัวเองต่อจากอุปกรณ์เดิม (ดูแนวคิดในบทความ [ONT กับเราเตอร์ ต่างกันอย่างไร](/fiber/ont-vs-router/)) สำหรับตัวอย่างขั้นตอนเปลี่ยนรหัสและชื่อ Wi-Fi บนเราเตอร์ ของผู้ให้บริการรายหนึ่ง ดูได้ที่ [ขั้นตอนเปลี่ยนรหัสผ่านและชื่อ Wi-Fi บนเราเตอร์](https://aisfibrepro.com/blog/ais-fibre-router-change-wifi-password-and-ssid/)

## ตรวจสอบหลังตั้งค่า

- ทดลองเชื่อมต่อด้วยรหัส Wi-Fi ใหม่จากโทรศัพท์หรือโน้ตบุ๊กสักเครื่อง
- เปิดรายการอุปกรณ์ที่เชื่อมต่อในหน้าตั้งค่า (ถ้ามี) และตรวจว่ามีเครื่องที่ไม่รู้จักหรือไม่
- จดรหัสแอดมินที่ตั้งใหม่ไว้ในที่ปลอดภัย เพราะถ้าลืมต้องรีเซ็ตเป็นค่าโรงงาน ซึ่งจะต้องตั้งค่าทั้งหมดใหม่ และค่าเริ่มต้นที่แปะไว้บนตัวเครื่องจะกลับมาใช้งานได้อีกครั้ง
- ตั้งเตือนตัวเองให้เข้ามาตรวจว่ามีเฟิร์มแวร์ใหม่หรือไม่เป็นระยะ

## คำถามที่พบบ่อย

### ควรเปลี่ยนรหัส Wi-Fi บ่อยแค่ไหน

แนวทางของ CISA เน้นที่คุณภาพของรหัส คือยาว สุ่ม และไม่ซ้ำ ไม่ได้กำหนดรอบเปลี่ยนตายตัว ข้อเสนอของบทความนี้คือ เปลี่ยนเมื่อรหัสถูกแจกให้คนที่ไม่ควรใช้ต่อ เมื่อสงสัยว่ารหัสรั่ว หรือเมื่อยังใช้รหัสเริ่มต้นที่ติดมากับเครื่องอยู่

### ต้องเปลี่ยนเราเตอร์ เป็นรุ่นที่รองรับ WPA3 ไหม

ไม่จำเป็นเสมอไป CISA ระบุว่า WPA2 AES ยังเป็นตัวเลือกที่ปลอดภัยพอ ให้ใช้ WPA3-Personal เมื่อเราเตอร์ และอุปกรณ์รองรับ แต่ถ้าเครื่องใช้การเข้ารหัสรุ่นเก่ากว่า WPA2 AES ควรเปลี่ยนค่า หรือขอเปลี่ยนเครื่อง

### ปิด UPnP แล้วเกมหรือแอปเชื่อมต่อไม่ได้ ทำอย่างไร

CISA ยอมรับว่าบางครั้งต้องเปิด UPnP ชั่วคราวเมื่อเพิ่มอุปกรณ์ ถ้าปิดแล้วใช้งานไม่ได้ให้เปิดพอร์ตที่แอปต้องการเองด้วย Port Forwarding แทนการเปิด UPnP ไว้ตลอด

### การซ่อนชื่อ Wi-Fi (SSID) ช่วยให้ปลอดภัยขึ้นไหม

ไม่ช่วย Apple ระบุว่าการซ่อนชื่อเครือข่ายไม่ได้ทำให้ตรวจไม่พบเครือข่าย และไม่ได้ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต อีกทั้งอุปกรณ์ที่เชื่อมต่อเครือข่ายที่ซ่อนชื่ออาจเปิดเผยข้อมูลที่ใช้ระบุตัวคุณได้ ส่วน CISA แนะนำให้เปลี่ยนชื่อเริ่มต้นและไม่ใส่ข้อมูลส่วนตัวในชื่อ สิ่งที่ช่วยจริงคือการเข้ารหัสที่ถูกต้องและรหัสที่แข็งแรง

### ลืมรหัสแอดมินของเราเตอร์ ทำอย่างไร

โดยทั่วไปเราเตอร์ มีปุ่มรีเซ็ตเป็นค่าโรงงาน เมื่อรีเซ็ตแล้วการตั้งค่าทั้งหมดจะกลับเป็นค่าเริ่มต้นตามสติกเกอร์ ต้องตั้งค่าและเปลี่ยนรหัสใหม่ทุกข้อ ถ้าเป็นเครื่องของผู้ให้บริการ ควรสอบถามผู้ให้บริการก่อนรีเซ็ต เพราะอาจต้องใส่ค่าการเชื่อมต่อใหม่
