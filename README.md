# NetLab TH

คลังความรู้อินเทอร์เน็ตและเครือข่ายภาษาไทย: https://athdevtech.github.io

Built with [Astro](https://astro.build) + [Starlight](https://starlight.astro.build). Articles live in `src/content/docs/`, and every push to `main` is built and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

```
npm install
npm run dev      # local preview
npm run build    # output in dist/
```
